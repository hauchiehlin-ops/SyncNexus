# คู่มือการใช้งาน Sync-Nexus (เวอร์ชัน macOS)

## 1. บทนำและภาพรวม
**Sync-Nexus for Mac** เป็นเครื่องมือซิงค์ไดเรกทอรีแบบสองทาง "Local-First / P2P" ที่ออกแบบมาสำหรับ macOS โดยเฉพาะ รองรับการซิงค์ระหว่างโฟลเดอร์ในเครื่อง, iCloud Drive, ไดรฟ์ภายนอก USB-C/Thunderbolt และอุปกรณ์ Android ในเครือข่าย Wi-Fi เดียวกัน

## 2. คุณสมบัติเฉพาะสำหรับ macOS
* **App Sandbox และ Security-Scoped Bookmarks**: สอดคล้องกับแนวทางของ Mac App Store จดจำสิทธิ์การเข้าถึงโฟลเดอร์ได้อย่างปลอดภัยแม้รีสตาร์ตเครื่อง
* **ระบบป้องกันความปลอดภัย APFS Snapshot**: สร้างสแนปช็อตของระบบไฟล์ก่อนซิงค์ไฟล์จำนวนมากเพื่อความปลอดภัยสูงสุด
* **FSEvents Kernel Monitoring**: ไม่ใช้ทรัพยากร CPU ขณะสแตนด์บาย ตรวจจับการเปลี่ยนแปลงไฟล์ได้ทันทีในระดับมิลลิวินาที
* **ดูตัวอย่างความแตกต่างและทดลองรัน (Trial Run)**: จำลองและดูตัวอย่างรายการไฟล์ที่จะเพิ่ม เปลี่ยนชื่อ หรือลบก่อนเริ่มซิงค์จริง
* **ค้นหาอุปกรณ์ในวงแลนด้วย Bonjour (P2P)**: เชื่อมต่อกับ Android หรือ Mac เครื่องอื่นในวง Wi-Fi เดียวกันโดยตรงโดยไม่ต้องผ่านคลาวด์

## 3. ขั้นตอนการใช้งาน

### ขั้นตอนที่ 1: เพิ่มโฟลเดอร์ซิงค์
1. เปิดแอป **Sync-Nexus.app**
2. คลิก **เพิ่มโฟลเดอร์…** บนแถบเครื่องมือ
3. เลือกโฟลเดอร์ที่ต้องการและอนุญาตสิทธิ์ผ่านหน้าต่างมาตรฐานของ macOS

### ขั้นตอนที่ 2: ดูตัวอย่างความแตกต่างและทดลองรัน
1. ไปที่แท็บ **ดูตัวอย่างความแตกต่าง**
2. คลิก **เริ่มการจำลองทดลองรัน**
3. ตรวจสอบรายการไฟล์แล้วคลิก **เริ่มการซิงค์ทันที**

### ขั้นตอนที่ 3: จัดการข้อขัดแย้ง
เมื่อไฟล์ถูกแก้ไขพร้อมกันในสองตำแหน่ง:
* ระบบจะเก็บไฟล์ทั้งสองเวอร์ชันไว้โดยไม่เขียนทับ
* เข้าไปที่แท็บ **ข้อขัดแย้ง** เพื่อเลือกรุ่นที่ต้องการบันทึกไว้
