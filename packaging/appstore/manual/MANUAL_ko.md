# Sync-Nexus 사용 설명서 (macOS 버전)

## 1. 개요 및 소개
**Sync-Nexus for Mac**은 macOS(Sonoma 및 Sequoia)를 위해 특별히 설계된 로컬 우선(Local-First) P2P 양방향 폴더 동기화 유틸리티입니다. 로컬 폴더, iCloud Drive, 외장 USB-C/Thunderbolt 드라이브, 동일 Wi-Fi 로컬 네트워크 내의 Android 기기 간의 안전한 자동 동기화를 지원합니다.

## 2. macOS 전용 핵심 기능
* **App Sandbox 및 보안 범위 북마크(Security-Scoped Bookmarks)**: Mac App Store 심사 지침을 철저히 준수하며, 재부팅 후에도 권한을 안전하게 유지합니다.
* **APFS 스냅샷 안전 보호**: 대규모 파일 동기화 작업 전에 APFS 스냅샷을 자동 생성하여 안전한 복원 지점을 확보합니다.
* **FSEvents 커널 실시간 감시**: 대기 중 CPU 사용량 0%를 유지하며, 파일 변경 시 밀리초 단위로 즉각 감지합니다.
* **차이 미리보기 및 시험 실행(Visual Diff Trial Run)**: 디스크에 적용하기 전에 추가, 수정, 삭제될 파일 목록을 사전에 시뮬레이션합니다.
* **Bonjour 로컬 네트워크 직결(P2P)**: 클라우드 서버 없이 동일 Wi-Fi 환경의 기기와 직접 통신합니다.

## 3. 단계별 사용 방법

### 1단계: 동기화 폴더 추가
1. **Sync-Nexus.app**을 실행합니다.
2. 툴바의 **폴더 추가…** 버튼을 클릭합니다.
3. 로컬 폴더, 외장 SSD, iCloud Drive 등 동기화할 폴더를 선택하고 권한을 허용합니다.

### 2단계: 차이 미리보기 및 시험 실행
1. 사이드바에서 **차이 미리보기** 탭을 선택합니다.
2. **시험 실행 시뮬레이션 시작**을 클릭합니다.
3. 변경 예정 목록을 검토한 후 **지금 동기화 적용**을 클릭합니다.

### 3단계: 충돌 해결
두 위치에서 동일한 파일이 동시에 수정된 경우:
* 파일이 덮어쓰이지 않고 안전하게 양쪽 버전이 모두 보존됩니다.
* **충돌** 탭에서 두 파일의 차이를 확인하고 유지할 버전을 선택합니다.
