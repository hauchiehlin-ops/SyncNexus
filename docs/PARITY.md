# 跨平台對齊清單（以 macOS 為基準）

目標：Android、Windows 的所有介面與功能對齊 macOS。平台做不到的項目，改用平台對應功能，並在同一版位保留「此平台不適用」說明。

狀態：⬜ 未開始　🟡 部分　✅ 已對齊

## 逐頁（依 macOS 側欄順序）

| # | 頁面 | macOS 內容 | Android | Windows |
|---|------|-----------|---------|---------|
| 1 | 概覽 | 狀態卡、**待確認群組清單（同意/取消）**、統計磚（追蹤檔案/最後深度驗證/舊版本）、端點卡片、同 Wi-Fi 近端設備 | 🟡 有狀態卡、群組卡、近端設備；缺待確認清單、統計磚 | 🟡 單一主視窗，無概覽頁；缺待確認清單 |
| 2 | 差異預覽 | 試跑報告、項目數、超過 100 項提示 | 🟡 有 PreviewSection | ⬜ |
| 3 | 資料夾 | 群組分頁列、待確認卡、目前群組橫幅（狀態晶片/暫停/恢復）、端點列（線上、可移除、exFAT 提示、更換資料夾、移除、顯示歷史） | 🟡 只有加入/移除 | 🟡 端點清單，缺更換資料夾、顯示歷史、狀態晶片 |
| 4 | 同步動態 | 速度欄、紀錄 | 🟡 | 🟡 |
| 5 | 衝突 | 衝突列表與處理 | 🟡 | 🟡 獨立視窗 |
| 6 | 舊版本 | 舊版本清單與還原、保留天數 | 🟡 | ⬜ |
| 7 | 驗證紀錄 | 深度驗證、疑似損毀 | 🟡 | ⬜ |
| 8 | 設定 | 群組管理、衝突策略、排除規則、雲端省空間、巢狀群組自動排除、語言、開機啟動、資料夾圖示 | ⬜ 只有語言、手冊、隱私政策 | ⬜ 只有開機啟動、資料夾圖示 |

## 平台對應

| macOS 功能 | Android 對應 | Windows 對應 |
|-----------|-------------|-------------|
| 開機啟動 | 開機廣播＋前景服務 | 登錄檔/工作排程（已有） |
| 資料夾圖示跟隨群組 | 不適用（標示） | 資料夾圖示（已有） |
| 選單列彈出視窗 | 常駐通知＋主畫面小工具 | 系統匣 |
| 通知點擊開啟確認 | 通知 PendingIntent 開啟待確認清單 | Toast 啟動參數 |
| exFAT 檔名相容提示 | 依儲存空間 SAF 提示 | 依磁碟檔案系統提示 |

## 限制

- 本機沒有 `dotnet`，Windows 端的修改無法在這台 Mac 編譯驗證，需在 Windows 或 CI 上建置。
- Android 同步引擎（`SyncEngine.kt` 約 350 行）比 macOS 的 `SyncCore` 簡單很多；衝突策略、排除規則、待確認（大量刪除門檻）等功能要先補引擎，介面才能對齊。
