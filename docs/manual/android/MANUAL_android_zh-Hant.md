# SyncNexus 操作使用手冊 — Android 篇

## 1. 簡介與核心架構
**SyncNexus for Android** 是一款針對 Android 手機與平板設計的本機優先雙向檔案同步工具。具備無伺服器、零雲端綁定、電量智慧感知與 USB 隨身碟支援。

* **儲存空間存取架構 (SAF)**：嚴格遵循 Google Play 分區儲存規範（Scoped Storage），由使用者手動授權目錄，權限安全持久化。
* **低電量智慧感知**：當手機電量低於 20% 且未連接充電器時，自動暫緩高負載對帳，保護手機日常續航。
* **USB OTG 隨身碟熱插拔感知**：插入外接 Type-C 隨身碟時即時偵測，支援加入為可移動端點。
* **同 Wi-Fi 跨平台發現**：透過 Android 網路服務發現（NSD），自動感知區域網路內的 Mac 與 Windows 設備。

## 2. 快速上手教學
1. **加入同步資料夾**：
   - 開啟應用程式，點擊 **「+ 加入資料夾」**。
   - 系統將開啟 Android 系統文件選擇器（SAF），選取您希望同步的文件目錄並點擊「使用這個資料夾」確認授權。
2. **端點多樣性設定**：
   - **內部儲存空間**：例如 `Documents/SyncFolder`。
   - **外接 SD 卡 / OTG 隨身碟**：選取外接儲存設備中的資料夾，SyncNexus 將標記為可移動端點。
3. **即時同步與背景運作**：
   - 點擊「立即對帳同步」觸發手動對帳。
   - 應用程式註冊了 Android 前台同步服務（Foreground Service）與定時背景工作（WorkManager），只要接通電源即可在背景自動保持最新狀態。

---

## 3. 衝突與安全保障
* **衝突保留**：若手機與電腦同時在離線狀態修改相同檔案，系統保留雙方版本，絕不靜默覆蓋。
* **零雲端遙測**：手機檔案內容絕不上傳至任何外部第三方伺服器，安全可信賴。
