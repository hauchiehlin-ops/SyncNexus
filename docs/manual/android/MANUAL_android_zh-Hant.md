# SyncNexus 操作使用手冊 — Android 篇

## 1. 簡介與特色
**SyncNexus for Android** 是專為 Android 手機與平板打造的本機優先檔案即時同步工具。不依賴外部雲端伺服器，直接透過同 Wi-Fi 區域網路與電腦進行高速同步。

* **原生 Android 儲存權限**：採用 Google 官方 Storage Access Framework (SAF)，只存取您選定的資料夾。
* **背景前台同步服務**：具備系統常駐通知，確保螢幕關閉時檔案同步依然順暢運作。
* **P2P 區域直連**：支援 Android NSD，同 Wi-Fi 內自動發現 Mac 與 Windows 電腦。

---

## 2. 快速上手：如何加入同步資料夾？

在主畫面點擊「**新增資料夾**」：

1. **手機內部儲存空間資料夾**：
   - 在彈出的系統檔案選擇器中，點選左上角選單圖示，點選您的手機名稱或「內部儲存空間」，選擇您想要同步的目錄，並點擊「使用這個資料夾」。
2. **外接 SD 卡或 USB 隨身碟**：
   - 將 SD 卡或 Type-C 隨身碟插入手機。在檔案選擇器的左側選單中，點選您的「SD 卡」或隨身碟裝置，選取準備要同步的目錄，並點擊「使用這個資料夾」。

---

## 3. 自動同步與注意事項

* **同 Wi-Fi 自動連線**：只要手機與 Mac 或 Windows 電腦連接在同一個 Wi-Fi，SyncNexus 就會自動偵測對齊檔案。
* **省電最佳化**：如需長時間於背景同步大型檔案，建議在系統設定中允許 SyncNexus「不受限制的電池使用」。
