# SyncNexus 操作使用手册 — Windows 完整指南

> **适用平台**：Windows 10 / Windows 11 (64-bit)  
> **当前版本**：1.2.0（build 22）  
> **核心设计原则**：本机优先（Local-First）、零云端服务器依赖、回收站优先（Recycle Bin First）

---

## 页眉控制栏功能说明

在 Windows 窗口顶部，配置了全局导航栏：

```
[ 当前页面标题 ] ------------------------- [ 语言切换下拉菜单 ▾ ] [ 📖 操作手册 ] [ 🛡️ 隐私政策 ]
```

1. **语言切换下拉菜单**：
   - **实际位置**：页眉右上角。
   - **功能用途**：即时切换 6 种界面语言（繁体中文、简体中文、English、日本語、한국어、ภาษาไทย）。
   - **操作方式**：点击展开下拉菜单，选取目标语言，整个应用程序界面立即切换，无需重启。
2. **操作手册按钮（📖 图标）**：
   - **实际位置**：语言菜单右侧。
   - **功能用途**：直接在应用内对话框中打开本操作手册，无需联网，也不会跳转到外部浏览器。
   - **操作方式**：点击打开，随时查阅；按 `Esc` 或“关闭”即可返回工作界面。
3. **隐私政策按钮（🛡️ 图标）**：
   - **实际位置**：手册按钮右侧。
   - **功能用途**：说明我们本机优先的同步隐私承诺，以及零云端传输的保护措施。

## 第一章：概览 (Overview)

### 1.1 功能与目的
**概览**是 Windows 用户的全局健康仪表板，呈现文件夹在线/离线状态、已跟踪文件总数、最近一次 SHA-256 验证时间、历史版本占用空间，以及局域网 P2P 设备发现。

### 1.2 【零基础新手教程：逐步操作】
- **【步骤 1：查看顶部控制栏】**：查看右上角的语言选择器、“操作手册 📖”与“隐私 🛡️”按钮，可随时点击切换语言或查阅手册。
- **【步骤 2：查看整体健康状态】**：左上角的健康徽章在一切正常时显示绿色“全部正常”；若有文件夹断线或有待处理的冲突，则显示黄色“警告”。
- **【步骤 3：处理大量删除保护】**：若单次删除超过 25 个文件或超过 25% 的文件，同步会自动暂停并出现“检查并确认”横幅，点击后可批准或还原。
- **【步骤 4：查看端点与局域网 P2P】**：中央的网格显示当前群组中所有文件夹的状态；同一 Wi-Fi 下附近的 Mac 与 Android 设备会通过 mDNS/UDP 自动被发现。

### 1.3 控件、位置与安全防护

| 控件 / 元素 | 界面位置 | 功能与目的 | 操作方式 | 预期结果与防护 |
| :--- | :--- | :--- | :--- | :--- |
| **整体健康状态** | 顶部标题区 | 整体同步健康状况 | 自动持续监控 | 绿色“全部正常”；出现断线、冲突或大量删除时变为黄色“警告”。 |
| **大量删除保护** | 顶部标题下方（仅异常时出现） | 防止误删或勒索软件造成的清空 | 点击“**检查并确认**” | 一次删除超过 25 个文件或超过 25% 的文件时，拦截并暂停同步。 |
| **已跟踪文件** | 统计卡片 #1 | 各端点跟踪的文件总数 | 只读 | 标注“实时 SHA-256 跟踪”，随文件变化动态更新。 |
| **最近深度验证** | 统计卡片 #2 | 上次 SHA-256 完整性检查的时间 | 只读 | 显示“无异常”或“X 个疑似损坏”，提醒您采取行动。 |
| **旧版本** | 统计卡片 #3 | 版本归档占用的存储空间 | 只读 | 例如“24.5 MB · 保留 30 天，可随时还原”。 |
| **端点状态卡片** | 中央网格区 | 每个同步文件夹的状态与路径 | 查看卡片信息 | 显示绿色“在线”或黄色“离线”；外接磁盘会标示“ExFAT”。 |
| **局域网 P2P 直连卡片** | 底部网络区 | 发现 Wi-Fi 上的 Mac、PC 与 Android 设备 | 持续发现 | 显示发现的设备名称与绿色“在线”标签，可直接 P2P 传输。 |

## 第二章：差异预览 (Diff Preview)

### 2.1 功能与目的
在把变更写入目标磁盘之前，**差异预览**提供无风险的**试运行模拟 (Dry-Run)**，让您预先查看即将进行的复制、重命名与删除。

### 2.2 【零基础新手教程：逐步操作】
- **【步骤 1：点击“执行试算模拟”】**：点击左上卡片上的蓝色“执行试算模拟”按钮。计算期间按钮会变为“模拟中...”，只在内存中计算差异，不会动到磁盘上的文件。
- **【步骤 2：查看预览符号】**：下方展开列表：绿色 `+`（新增复制）、蓝色 `➔`（智能重命名）、红色 `−`（删除，会先移入回收站）。
- **【步骤 3：点击“确认并同步”】**：确认列表无误后，点击右下角的“确认并同步”，将变更应用到所有磁盘；顶部的 Toast 通知会提示完成。

### 2.3 控件、位置与安全防护

| 按钮 / 控件 | 界面位置 | 功能与目的 | 操作方式 | 预期结果与防护 |
| :--- | :--- | :--- | :--- | :--- |
| **执行试算模拟** | 主卡片左上角（蓝色按钮） | 模拟所有端点之间的对账 | 点击按钮 | 变为“模拟中...”，随后在下方显示变更预览列表。 |
| **确认并同步** | 预览列表右下角 | 将已确认的变更写入目标磁盘 | 点击确认 | 启动同步引擎；顶部浮动提示确认同步成功。 |

> **预览符号**：
> - 🟢 **`+`（绿色）**：预定新增或复制的文件。
> - 🔵 **`➔`（蓝色）**：预定在本机重命名的文件。
> - 🔴 **`−`（红色）**：预定删除的文件（**保证：先移入 Windows 回收站，绝不永久清除**）。

## 第三章：文件夹 (Folders)

### 3.1 功能与多文件夹同步群组
**文件夹**页使用**文件夹群组架构**来配置和管理您的同步网络：
- **多任务独立同步**：可同时创建多个互相独立的同步群组（例如工作、家庭照片、个人财务）。
- **独立管道与共识**：每个群组拥有自己的文件夹与 SQLite 共识存储；某个群组的大型同步绝不会卡住其他群组！

### 3.2 【零基础新手教程：逐步操作】
- **【步骤 1：创建与切换同步群组】**：
  1. 点击顶部的“**+ 新增群组**”，输入名称并选择图标后保存。
  2. 点击群组标签切换当前群组。
  3. 点击“**✎ 编辑同步群组**”可重命名或删除群组（磁盘上的实际文件不受影响）。
- **【步骤 2：点击“添加文件夹...”】**：点击底部的“**添加文件夹...**”打开 Windows 文件资源管理器（每个群组至少需要 2 个文件夹）。
- **【步骤 3：从 5 种存储位置中选择】**：
  1. **本机文件夹**：打开文件资源管理器 ➔ 点击“文档”或进入 `C:` 盘 ➔ 选择文件夹。
  2. **OneDrive 云端硬盘**：打开文件资源管理器 ➔ 点击侧边栏的“OneDrive” ➔ 选择文件夹。
  3. **Google Drive**：打开文件资源管理器 ➔ 点击“Google Drive” ➔ “我的云端硬盘” ➔ 选择目录。
  4. **iCloud Drive（Windows）**：打开文件资源管理器 ➔ 点击侧边栏的“iCloud Drive” ➔ 选择目录。
  5. **外接 U 盘 / 便携硬盘**：插入 U 盘 ➔ 打开文件资源管理器 ➔ 点击盘符（例如 `D:` 或 `E:`）➔ 选择文件夹（**强烈建议使用 ExFAT 格式**）。
- **【步骤 4：重新链接或移除】**：若文件夹被移动，点击“**更改文件夹...**”；点击“**移除...**”可解除绑定（解除绑定绝不会删除实际文件）。

### 3.3 控件、位置与安全防护

| 控件 / 元素 | 界面位置 | 功能与目的 | 操作方式 | 预期结果与防护 |
| :--- | :--- | :--- | :--- | :--- |
| **+ 新增群组** | 顶部同步群组栏 | 创建新的独立同步群组 | 点击并输入名称与图标 | 出现新的群组标签；自动切换到空白状态。 |
| **✎ 编辑同步群组** | 当前群组信息右侧 | 重命名、更换图标或删除群组 | 点击打开编辑面板 | 支持重命名；删除只解除绑定，不碰实际文件。 |
| **添加文件夹...** | 文件夹列表底部（蓝色按钮） | 将目录加入同步网络 | 点击并在资源管理器中选择 | 写入唯一的 `.syncnexus-endpoint` UUID 标记文件。 |
| **更改文件夹...** | 每张端点卡片右侧 | 盘符或路径变更时重新链接 | 点击并选择新路径 | 验证标记并自动恢复连接。 |
| **移除...** | 每张端点卡片右侧 | 将文件夹从同步群组解除绑定 | 点击并确认对话框 | 解除同步绑定，**绝不删除实际文件**。 |

## 第四章：冲突 (Conflicts)

### 4.1 功能与目的
当两台设备离线并发编辑同一文件时，SyncNexus 严格执行**零覆盖策略**，把冲突文件另存为 `文件名 (conflict ...)`，集中在此处供并排比较与处理。

### 4.2 【零基础新手教程：逐步操作】
- **【步骤 1：查看红色冲突徽章】**：发生离线并发编辑时，侧边栏“冲突”图标上会出现红色徽章，点击进入。
- **【步骤 2：查看双栏卡片】**：左侧卡片显示“当前版本”，右侧卡片显示“端点版本”（带绿色“较新”徽章），并列出大小、修改日期与来源。
- **【步骤 3：在文件资源管理器中显示】**：点击“在文件资源管理器中显示”，会定位到该文件，方便用文本编辑器比较。
- **【步骤 4：选择处理方式】**：
  - 点击左侧“**保留此版本**”：保留主文件，推送到所有端点，并将冲突副本归档。
  - 点击右侧“**使用此版本**”：把冲突副本升级为正式主文件，并将原主文件备份到旧版本。

### 4.3 控件、位置与安全防护

| 按钮 / 控件 | 界面位置 | 功能与目的 | 操作方式 | 预期结果与防护 |
| :--- | :--- | :--- | :--- | :--- |
| **保留此版本** | 左侧“当前版本”卡片底部 | 保留主文件以解决冲突 | 点击按钮 | 主文件保持为正式版本并传播到其他端点；冲突副本被安全归档。 |
| **使用此版本** | 右侧“端点版本”卡片底部 | 采用传入的副本以解决冲突 | 点击按钮 | 冲突副本成为正式文件；原主文件备份到旧版本。 |
| **在文件资源管理器中显示** | 两张版本卡片内 | 在文件资源管理器中显示实际文件 | 点击按钮 | 打开文件资源管理器并选中文件，方便手动检查文本或比对差异。 |
| **无冲突状态** | 全部处理完毕时的空状态 | 确认所有文件已一致 | 只读 | 显示绿色勾选“没有待处理的冲突，所有文件完全一致”。 |

## 第五章：旧版本 (Versions)

### 5.1 功能与目的
每当文件被覆盖或同步时，被取代的版本会归档到 `.syncnexus-history`，让您随时一键回滚。

### 5.2 【零基础新手教程：逐步操作】
- **【步骤 1：设置保留策略】**：在顶部下拉菜单选择保留期限（7 / 30 / 90 天或永久）；过期文件会在后台自动清理。
- **【步骤 2：搜索目标版本】**：在右上角搜索栏输入文件名关键字，即可立即筛选版本。
- **【步骤 3：点击“还原”恢复文件】**：在版本卡片上点击“**还原**”，文件会立即恢复到工作目录，并在 2 秒内同步到所有端点。
- **【步骤 4：存储维护（可选）】**：点击“立即清理过期”清除过期备份，或点击“全部清除”并确认后清空归档（正在使用的文件绝不受影响）。

### 5.3 控件、位置与安全防护

| 按钮 / 控件 | 界面位置 | 功能与目的 | 操作方式 | 预期结果与防护 |
| :--- | :--- | :--- | :--- | :--- |
| **保留策略菜单** | 顶部卡片“自动清理”右侧 | 设置最长保留期限 | 选择：7 / 30 / 90 天或永久 | 超过指定天数的文件会在后台自动清除。 |
| **立即清理过期** | 保留菜单旁 | 立即手动清除过期版本 | 点击按钮 | 立即释放磁盘空间并更新顶部统计。 |
| **全部清除** | “立即清理过期”旁 | 完全清空历史归档 | 点击并确认提示 | 仅清除历史归档，**绝不影响正在使用的文件**。 |
| **搜索筛选** | 版本列表右上角 | 按文件名或端点筛选版本 | 输入关键字 | 立即筛选列表。 |
| **还原** | 每条版本记录右侧 | 把选定版本恢复到文件夹 | 点击“**还原**” | 以选定版本覆盖当前文件，并同步到所有端点。 |

## 第六章：验证 (Verification)

### 6.1 功能与目的
SyncNexus 使用 **SHA-256 加密哈希算法**逐字节验证所有端点，防止传输不完整与磁盘的无声损坏（位衰减，bit-rot）。

### 6.2 【零基础新手教程：逐步操作】
- **【步骤 1：开始深度验证】**：点击中央卡片上的蓝色“立即开始验证”按钮，引擎会在后台计算所有端点的 SHA-256 哈希。
- **【步骤 2：查看验证报告】**：完成后会更新“最近深度验证”时间。全部一致时显示绿色徽章“全部正常”；若检测到损坏，则列出受损文件。
- **【步骤 3：修复损坏文件】**：
  - 点击“**从其他端点修复**”：从健康端点下载位对位正确的副本替换受损文件（受损文件会先备份到历史记录）。
  - 点击“**接受当前内容**”：若该变更是您有意为之，则重新计算基准哈希并清除警告。

### 6.3 控件、位置与安全防护

| 按钮 / 控件 | 界面位置 | 功能与目的 | 操作方式 | 预期结果与防护 |
| :--- | :--- | :--- | :--- | :--- |
| **立即开始验证** | 中央卡片右侧（蓝色按钮） | 启动深度 SHA-256 哈希计算 | 点击“**立即开始验证**” | 后台计算；完成后更新时间与异常列表。 |
| **从其他端点修复** | 检测到损坏文件时出现 | 从健康端点下载正确的文件 | 点击修复 | 从健康端点下载原始副本；被取代的损坏文件会保存在历史记录中。 |
| **接受当前内容** | 检测到损坏文件时出现 | 若变更是有意的，则更新基准哈希 | 点击接受 | 在共识存储中重新计算基准哈希；移除警告徽章。 |

## 第七章：设置 (Settings)

### 7.1 功能与目的
个性化的同步偏好、排除过滤器、语言切换与开机启动。

### 7.2 【零基础新手教程：逐步操作】
- **【步骤 1：选择冲突策略】**：选择“两个版本都保留，由我决定（推荐）”或“较新者胜出，旧版保存到旧版本”。
- **【步骤 2：配置排除开关】**：切换 `node_modules`、`.git`、SQLite 锁文件（`-wal`、`-shm`）的排除开关。被排除的项目绝不会传输。
- **【步骤 3：设置语言与启动】**：从 6 种界面语言中选择；开启“登录时启动”，即可在 Windows 系统托盘中静默启动。
- **【步骤 4：查看日志与指南】**：点击“打开日志文件”，在记事本中查看同步诊断；点击“新手引导”可重新查看入门教程。

### 7.3 控件、位置与安全防护

| 设置项 | 界面位置 | 功能与目的 | 选项与操作 | 预期结果与防护 |
| :--- | :--- | :--- | :--- | :--- |
| **冲突策略** | 顶部卡片 | 设置并发编辑时的仲裁行为 | 单选：<br>1. **两个版本都保留，由我决定**（默认）<br>2. **较新者胜出，旧版保存到旧版本** | 选项 1 会保存 `.conflict` 文件；选项 2 自动采用时间戳最新的版本。 |
| **排除开关** | 第二张卡片 | 避免不必要或易变的文件被同步 | 切换开关：<br>• `node_modules`<br>• `.git`<br>• 数据库锁（`-wal`、`-shm`） | 启用后，匹配的文件保持原样并在同步时跳过，节省带宽。 |
| **界面语言** | 第三张卡片顶部 | 设置显示语言 | 6 种语言的下拉菜单 | 立即切换整个应用程序界面语言。 |
| **开机启动** | 语言选择器下方 | 设置 SyncNexus 是否随 Windows 启动 | 切换开关 | 登录后在系统托盘静默运行，让同步始终保持有效。 |
| **打开日志文件** | 左下角按钮 | 查看实时同步诊断 | 点击按钮 | 在记事本中打开实时日志。 |
| **新手引导** | “打开日志文件”旁 | 重新打开初始欢迎向导 | 点击按钮 | 弹出引导向导，可重新查看入门教程。 |

## 总结：日常安心守则

1. **无需手动点击，自在工作**：只要文件夹显示“在线”，保存或重命名文件都会在 2 秒内同步到所有端点。
2. **有疑虑就先模拟**：批量整理或删除文件之前，先到“差异预览”点击“执行试算模拟”。
3. **删掉文件也别慌**：先查看 Windows 回收站；若已清空，打开“旧版本”，搜索该文件并点击“还原”。您的数据始终安全！
