# SyncNexus 操作マニュアル — Windows 完全ガイド

> **対応プラットフォーム**：Windows 10 / Windows 11 (64-bit)  
> **現在のバージョン**：1.2.0（build 22）  
> **設計の基本方針**：ローカルファースト、クラウドサーバー非依存、ごみ箱が最優先 (Recycle Bin First)

---

## 上部ヘッダーの操作

Windows アプリのウィンドウ最上部には、グローバルナビゲーションバーがあります：

```
[ 現在のページ名 ] ------------------------- [ 言語メニュー ▾ ] [ 📖 マニュアル ] [ 🛡️ プライバシー ]
```

1. **言語ドロップダウンメニュー**：
   - **場所**：ヘッダー右上。
   - **用途**：6 つの表示言語（繁体字中国語、簡体字中国語、English、日本語、한국어、ภาษาไทย）を即座に切り替えます。
   - **操作方法**：クリックしてメニューを開き、言語を選ぶと、再起動なしでアプリ全体の言語がすぐに切り替わります。
2. **操作マニュアルボタン（📖 アイコン）**：
   - **場所**：言語メニューの右側。
   - **用途**：このマニュアルをアプリ内ダイアログで直接開きます。インターネット接続は不要で、外部ブラウザも開きません。
   - **操作方法**：クリックして開き、いつでも参照できます。`Esc` または「閉じる」で作業画面に戻ります。
3. **プライバシーポリシーボタン（🛡️ アイコン）**：
   - **場所**：マニュアルボタンの右側。
   - **用途**：ローカルファーストな同期におけるプライバシーへの取り組みと、クラウドへ一切送信しない保護の内容を説明します。

## 第 1 章：概要 (Overview)

### 1.1 目的
**概要**は、Windows ユーザー向けの全体ヘルスダッシュボードです。フォルダーのオンライン/オフライン状態、追跡中のファイル総数、最後の SHA-256 検証時刻、履歴バージョンの使用量、ローカルネットワークでの P2P 検出を表示します。

### 1.2 【初心者向けステップバイステップ】
- **【ステップ 1：上部のコントロールバーを確認】**：右上の言語選択、「操作マニュアル 📖」、「プライバシー 🛡️」ボタンを確認します。いつでもクリックして言語を切り替えたり、マニュアルを開いたりできます。
- **【ステップ 2：全体の状態を確認】**：左上のステータスバッジは、すべて正常なら緑の「すべて正常」、フォルダーが切断されている、または競合が未処理の場合は黄色の「警告」になります。
- **【ステップ 3：大量削除の保護に対応】**：1 回の処理で 25 ファイル超、または 25% 超のファイルが削除されると、同期が自動的に停止し「確認して承認」バナーが表示されます。クリックして承認または復元します。
- **【ステップ 4：エンドポイントと LAN P2P を確認】**：中央のグリッドに、現在のグループ内の全フォルダーの状態が表示されます。同じ Wi-Fi 上の Mac や Android デバイスは mDNS/UDP で自動的に検出されます。

### 1.3 コントロール、場所、安全対策

| コントロール / 要素 | 画面上の場所 | 目的 | 操作方法 | 期待される結果と安全対策 |
| :--- | :--- | :--- | :--- | :--- |
| **全体ヘルスステータス** | 上部のタイトル領域 | 同期全体の健全性 | 自動で常時監視 | 緑の「すべて正常」。切断、競合、大量削除があると黄色の「警告」に変わります。 |
| **大量削除の保護** | 上部タイトルの下（異常時のみ） | 誤削除やランサムウェアによる消去を防止 | 「**確認して承認**」をクリック | 一度に 25 ファイル超、または 25% 超のファイルが削除されると、同期を遮断して一時停止します。 |
| **追跡中のファイル** | 統計タイル #1 | 各エンドポイントで追跡しているファイルの総数 | 読み取り専用 | 「リアルタイム SHA-256 追跡」と表示され、ファイルの変更に応じて動的に更新されます。 |
| **最後の詳細検証** | 統計タイル #2 | 最後に SHA-256 整合性チェックを行った時刻 | 読み取り専用 | 「異常なし」または「破損の疑い X 件」を表示し、対応を促します。 |
| **旧バージョン** | 統計タイル #3 | バージョンアーカイブが使用している容量 | 読み取り専用 | 例：「24.5 MB · 30 日間保持、いつでも復元可能」。 |
| **エンドポイント状態カード** | 中央のグリッド領域 | 同期対象の各フォルダーの状態とパス | カードの情報を確認 | 緑の「オンライン」または黄色の「オフライン」を表示。外付けドライブには「ExFAT」と表示されます。 |
| **LAN P2P 直接接続カード** | 下部のネットワーク領域 | Wi-Fi 上の Mac、PC、Android デバイスを検出 | 継続的に検出 | 検出したデバイス名と緑の「オンライン」チップを表示し、直接 P2P 転送できます。 |

## 第 2 章：差分プレビュー (Diff Preview)

### 2.1 目的
変更を対象ディスクに反映する前に、**差分プレビュー**がリスクのない**ドライラン（試験実行）**を行い、予定されているコピー、名前変更、削除を確認できます。

### 2.2 【初心者向けステップバイステップ】
- **【ステップ 1：「試算シミュレーションを実行」をクリック】**：左上のカードにある青い「試算シミュレーションを実行」ボタンをクリックします。計算中はボタンが「シミュレーション中...」に変わり、ディスク上のファイルには触れずにメモリ内で差分を計算します。
- **【ステップ 2：プレビューの記号を確認】**：下にリストが展開されます。緑の `+`（新規コピー）、青の `➔`（スマートな名前変更）、赤の `−`（削除。先にごみ箱へ移動）。
- **【ステップ 3：「確認して同期」をクリック】**：リストに問題がなければ、右下の「確認して同期」をクリックして全ディスクに反映します。完了すると上部にトースト通知が表示されます。

### 2.3 コントロール、場所、安全対策

| ボタン / コントロール | 画面上の場所 | 目的 | 操作方法 | 期待される結果と安全対策 |
| :--- | :--- | :--- | :--- | :--- |
| **試算シミュレーションを実行** | メインカード左上（青いボタン） | 全エンドポイント間の照合をシミュレート | ボタンをクリック | 「シミュレーション中...」に変わり、その後、下に変更プレビューのリストが表示されます。 |
| **確認して同期** | プレビューリストの右下 | 確認済みの変更を対象ディスクに書き込む | クリックして確定 | 同期エンジンが起動し、上部に成功を知らせるトーストが表示されます。 |

> **プレビューの記号**：
> - 🟢 **`+`（緑）**：追加またはコピーされる予定のファイル。
> - 🔵 **`➔`（青）**：ローカルで名前が変更される予定のファイル。
> - 🔴 **`−`（赤）**：削除される予定のファイル（**保証：先に Windows のごみ箱へ移動し、完全には消去しません**）。

## 第 3 章：フォルダー (Folders)

### 3.1 目的とマルチフォルダー同期グループ
**フォルダー**タブでは、**フォルダーグループ構成**を使って同期ネットワークを設定・管理します：
- **マルチタスクの独立した同期**：複数の独立した同期グループ（仕事、家族の写真、家計など）を同時に作成できます。
- **独立したパイプラインと合意**：各グループは専用のフォルダーと SQLite の合意ストアを持つため、あるグループの大規模な同期が他のグループを止めることはありません！

### 3.2 【初心者向けステップバイステップ】
- **【ステップ 1：同期グループの作成と切り替え】**：
  1. 上部の「**+ 新規グループ**」をクリックし、名前とアイコンを選んで保存します。
  2. グループのチップをクリックして、使用中のグループを切り替えます。
  3. 「**✎ 同期グループを編集**」をクリックすると、名前の変更やグループの削除ができます（ディスク上の実ファイルは残ります）。
- **【ステップ 2：「フォルダーを追加...」をクリック】**：下部の「**フォルダーを追加...**」をクリックして Windows エクスプローラーを開きます（1 グループにつき 2 つ以上のフォルダーが必要）。
- **【ステップ 3：5 種類の保存場所から選ぶ】**：
  1. **ローカル PC のフォルダー**：エクスプローラーを開く ➔「ドキュメント」をクリック、または `C:` ドライブ内へ移動 ➔ フォルダーを選択。
  2. **OneDrive**：エクスプローラーを開く ➔ サイドバーの「OneDrive」をクリック ➔ フォルダーを選択。
  3. **Google Drive**：エクスプローラーを開く ➔「Google Drive」➔「マイドライブ」➔ ディレクトリを選択。
  4. **iCloud Drive（Windows）**：エクスプローラーを開く ➔ サイドバーの「iCloud Drive」をクリック ➔ ディレクトリを選択。
  5. **外付け USB フラッシュ / ポータブルドライブ**：USB ドライブを接続 ➔ エクスプローラーを開く ➔ ドライブ文字（例：`D:` や `E:`）をクリック ➔ フォルダーを選択（**ExFAT 形式を強く推奨**）。
- **【ステップ 4：再リンクまたは削除】**：フォルダーを移動した場合は「**フォルダーを変更...**」をクリックします。「**削除...**」をクリックすると連携を解除します（解除しても実ファイルは削除されません）。

### 3.3 コントロール、場所、安全対策

| コントロール / 要素 | 画面上の場所 | 目的 | 操作方法 | 期待される結果と安全対策 |
| :--- | :--- | :--- | :--- | :--- |
| **+ 新規グループ** | 上部の同期グループバー | 新しい独立した同期グループを作成 | クリックして名前とアイコンを入力 | 新しいグループのチップが表示され、空の状態に自動で切り替わります。 |
| **✎ 同期グループを編集** | 使用中グループ情報の右側 | 名前変更、アイコン変更、グループ削除 | クリックして編集シートを開く | 名前の変更に対応。削除は連携解除のみで、実ファイルには触れません。 |
| **フォルダーを追加...** | フォルダー一覧の下部（青いボタン） | ディレクトリを同期ネットワークに追加 | クリックしてエクスプローラーで選択 | 固有の `.syncnexus-endpoint` UUID マーカーファイルを書き込みます。 |
| **フォルダーを変更...** | 各エンドポイントカードの右側 | ドライブ文字やパスが変わった場合に再リンク | クリックして新しいパスを選択 | マーカーを検証し、接続を自動的に復元します。 |
| **削除...** | 各エンドポイントカードの右側 | フォルダーを同期グループから解除 | クリックしてダイアログで確認 | 同期との連携を解除します。**実ファイルは削除されません**。 |
| **マーカーによる保護** | エンドポイントカードの状態欄 | USB ドライブの挿し間違いを防止 | 継続的な自動検証 | 間違ったドライブが挿入されると「マーカーが一致しないため伝播を停止しました」と表示し、自動的に隔離します！ |

## 第 4 章：競合 (Conflicts)

### 4.1 目的
2 台のデバイスでオフライン中に同時編集が起きた場合、SyncNexus は厳格な**上書きゼロ方針**に従い、競合したファイルを `ファイル名 (conflict ...)` として保存し、ここに集めて並べて比較・解決できるようにします。

### 4.2 【初心者向けステップバイステップ】
- **【ステップ 1：赤い競合バッジを確認】**：オフラインでの同時編集が起きると、サイドバーの「競合」アイコンに赤いバッジが表示されます。クリックして開きます。
- **【ステップ 2：2 列のカードを確認】**：左のカードに「現在のバージョン」、右のカードに「エンドポイントのバージョン」（緑の「新しい」バッジ付き）が表示され、サイズ、更新日時、取得元がわかります。
- **【ステップ 3：エクスプローラーで表示】**：「エクスプローラーで表示」をクリックするとファイルが選択され、テキストエディターで比較できます。
- **【ステップ 4：解決方法を選択】**：
  - 左の「**このバージョンを保持**」：メインファイルを保持して全エンドポイントに反映し、競合コピーはアーカイブします。
  - 右の「**このバージョンを使用**」：競合コピーを正式なメインファイルに昇格し、以前のメインファイルは旧バージョンにバックアップします。

### 4.3 コントロール、場所、安全対策

| ボタン / コントロール | 画面上の場所 | 目的 | 操作方法 | 期待される結果と安全対策 |
| :--- | :--- | :--- | :--- | :--- |
| **このバージョンを保持** | 左の「現在のバージョン」カード下部 | メインファイルを保持して競合を解決 | ボタンをクリック | メインファイルが正式版のまま他のエンドポイントに伝播し、競合コピーは安全にアーカイブされます。 |
| **このバージョンを使用** | 右の「エンドポイントのバージョン」カード下部 | 受信したコピーを採用して競合を解決 | ボタンをクリック | 競合コピーが正式なファイルになり、以前のメインファイルは旧バージョンにバックアップされます。 |
| **エクスプローラーで表示** | 両方のバージョンカード内 | エクスプローラーで実ファイルを表示 | ボタンをクリック | エクスプローラーが開いてファイルが選択され、手動でのテキスト確認や差分比較ができます。 |
| **競合なしの状態** | すべて解決したときの空の画面 | すべてのファイルが一致していることを確認 | 読み取り専用 | 緑のチェックマークと「未処理の競合はありません。すべてのファイルが同一です」を表示します。 |

## 第 5 章：旧バージョン (Versions)

### 5.1 目的
ファイルが上書き・同期されるたびに、置き換えられた版が `.syncnexus-history` にアーカイブされ、いつでもワンクリックでロールバックできます。

### 5.2 【初心者向けステップバイステップ】
- **【ステップ 1：保持ポリシーを設定】**：上部のドロップダウンで保持期間（7 / 30 / 90 日または無期限）を選びます。期限を過ぎたファイルはバックグラウンドで自動的に整理されます。
- **【ステップ 2：対象のバージョンを検索】**：右上の検索バーにファイル名のキーワードを入力すると、すぐにバージョンが絞り込まれます。
- **【ステップ 3：「復元」をクリックしてファイルを取り戻す】**：バージョンカードの「**復元**」をクリックします。ファイルは作業ディレクトリに即座に戻り、2 秒以内に全エンドポイントへ同期されます。
- **【ステップ 4：ストレージの管理（任意）】**：「期限切れを今すぐ整理」で古いバックアップを削除するか、「すべてクリア」で確認後にアーカイブを空にします（使用中のファイルには影響しません）。

### 5.3 コントロール、場所、安全対策

| ボタン / コントロール | 画面上の場所 | 目的 | 操作方法 | 期待される結果と安全対策 |
| :--- | :--- | :--- | :--- | :--- |
| **保持ポリシーメニュー** | 上部カードの「自動クリーンアップ」の右 | 最長の保持期間を設定 | 7 / 30 / 90 日または無期限を選択 | 指定日数を過ぎたファイルは、バックグラウンドで自動的に削除されます。 |
| **期限切れを今すぐ整理** | 保持メニューの横 | 期限切れのバージョンを手動ですぐに削除 | ボタンをクリック | ディスク容量をすぐに解放し、上部の統計を更新します。 |
| **すべてクリア** | 「期限切れを今すぐ整理」の横 | 履歴アーカイブを完全に空にする | クリックして警告で確認 | 履歴アーカイブのみを消去します。**使用中のファイルには影響しません**。 |
| **検索フィルター** | バージョン一覧の右上 | ファイル名やエンドポイントでバージョンを絞り込み | キーワードを入力 | 一覧が即座に絞り込まれます。 |
| **復元** | 各バージョン記録の右側 | 選択したバージョンをフォルダーに戻す | 「**復元**」をクリック | 選択したバージョンで現在のファイルを置き換え、全エンドポイントに同期します。 |

## 第 6 章：検証 (Verification)

### 6.1 目的
SyncNexus は **SHA-256 暗号ハッシュアルゴリズム**を使って全エンドポイントのすべてのバイトを検証し、不完全な転送やディスクの気付きにくい破損（ビット腐敗、bit-rot）を防ぎます。

### 6.2 【初心者向けステップバイステップ】
- **【ステップ 1：詳細検証を開始】**：中央のカードにある青い「今すぐ検証を開始」ボタンをクリックします。エンジンがバックグラウンドで全エンドポイントの SHA-256 ハッシュを計算します。
- **【ステップ 2：検証レポートを確認】**：完了すると「最後の詳細検証」の時刻が更新されます。すべて一致していれば緑の「すべて正常」バッジ、破損が検出されると破損ファイルの一覧が表示されます。
- **【ステップ 3：破損ファイルを修復】**：
  - 「**他のエンドポイントから修復**」をクリック：正常なエンドポイントからビット単位で正確なコピーを取得し、破損ファイルを置き換えます（破損ファイルは先に履歴へバックアップされます）。
  - 「**現在の内容を受け入れる**」をクリック：意図した変更であれば、基準ハッシュを再計算して警告を消去します。

### 6.3 コントロール、場所、安全対策

| ボタン / コントロール | 画面上の場所 | 目的 | 操作方法 | 期待される結果と安全対策 |
| :--- | :--- | :--- | :--- | :--- |
| **今すぐ検証を開始** | 中央カードの右側（青いボタン） | SHA-256 ハッシュの詳細計算を開始 | 「**今すぐ検証を開始**」をクリック | バックグラウンドで計算し、終了時に時刻と異常リストを更新します。 |
| **他のエンドポイントから修復** | 破損ファイルを検出したときに表示 | 正常なエンドポイントから正しいファイルを取得 | クリックして修復 | 正常なエンドポイントから元の状態のコピーを取得し、置き換えられた破損ファイルは履歴に保存されます。 |
| **現在の内容を受け入れる** | 破損ファイルを検出したときに表示 | 意図した変更なら基準ハッシュを更新 | クリックして受け入れ | 合意ストア内の基準ハッシュを再計算し、警告バッジを消します。 |

## 第 7 章：設定 (Settings)

### 7.1 目的
同期の好みの設定、除外フィルター、言語の切り替え、スタートアップ時の起動を行います。

### 7.2 【初心者向けステップバイステップ】
- **【ステップ 1：競合ポリシーを選択】**：「両方を保持して自分で選ぶ（推奨）」または「新しいほうを優先し、古い版は旧バージョンに保存」を選びます。
- **【ステップ 2：除外スイッチを設定】**：`node_modules`、`.git`、SQLite のロックファイル（`-wal`、`-shm`）の除外スイッチを切り替えます。除外した項目は転送されません。
- **【ステップ 3：言語と起動を設定】**：6 つの表示言語から選択します。「ログイン時に起動」をオンにすると、Windows のシステムトレイで静かに起動します。
- **【ステップ 4：ログとガイドを確認】**：「ログファイルを開く」でメモ帳に同期の診断情報を表示し、「オンボーディングガイド」で初心者向けの説明を見直せます。

## まとめ：毎日を安心して使うためのルール

1. **手動操作なしで自由に作業**：フォルダーが「オンライン」と表示されていれば、ファイルの保存や名前変更は 2 秒以内に全エンドポイントへ同期されます。
2. **迷ったらシミュレーション**：大量のファイルを整理・削除する前に、「差分プレビュー」で「試算シミュレーションを実行」をクリックしましょう。
3. **削除したファイルも慌てない**：まず Windows のごみ箱を確認します。空にしてしまった場合は「旧バージョン」を開き、ファイルを検索して「復元」をクリックします。データは常に安全です！
