# SyncNexus 操作使用手冊 — Windows 完整指南

> **適用平台**：Windows 10 / Windows 11 (64-bit)  
> **目前版本**：1.2.0（build 22）  
> **核心設計原則**：本機優先（Local-First）、零雲端伺服器依賴、資源回收筒先行（Recycle Bin First）

---

## 頁首控制列功能說明

在 Windows 視窗頂部，配置了全域導覽列：

```
[ 當前頁面主題標題 ] ------------------------- [ 語系切換下拉選單 ▾ ] [ 📖 操作手冊 ] [ 🛡️ 隱私政策 ]
```

1. **語系切換下拉式選單**：
   - **實際位置**：頁首右上角第一個控制元件。
   - **功能用途**：支援即時切換 6 種介面語系（繁體中文、簡體中文、English、日本語、한국어、ภาษาไทย）。
   - **操作方式**：點擊展開下拉選單，選取目標語言，整個應用程式介面立即切換，無須重啟。
2. **操作說明手冊按鈕（📖 圖示）**：
   - **實際位置**：語系選單右側。
   - **功能用途**：直接以原生應用內對話框展開本操作手冊，免聯網、不開啟瀏覽器跳出。
   - **操作方式**：點擊開啟，隨時查閱各頁面功能與操作指引；按 `Esc` 或「關閉」隨時返回工作畫面。
3. **隱私權政策按鈕（🛡️ 圖示）**：
   - **實際位置**：操作手冊按鈕右側。
   - **功能用途**：呈現純本機同步的資料隱私承諾與零雲端傳輸保護。

## 第一章：概覽 (Overview)

### 1.1 頁面功能定位與目的
「概覽」是 Windows 使用者的**整體健康儀表板**。呈現同步端點在線狀態、監控檔案總量、上次 SHA-256 驗證時間與舊版本佔用容量，並提供同 Wi-Fi 內 P2P 設備搜尋。

### 1.2 【零基礎新手教學：手把手操作程序】
- **【步驟 1：檢視頁首控制列】**：主視窗頂部右側常駐「語系選單」、「操作手冊 📖」與「隱私政策 🛡️」，點擊可隨時切換語言或查閱手冊。
- **【步驟 2：確認全局健康燈號】**：左上方健康徽章顯示綠燈「全部正常」代表運作良好；黃燈「警告」代表有端點離線或待決衝突。
- **【步驟 3：應對大量刪除攔截卡片】**：若單次刪除超過 25 個檔案或 25%，系統自動暫停同步並出現「審核並確認」卡片，點擊確認或恢復，防止誤刪。
- **【步驟 4：查看端點與同網 P2P】**：中央卡片列出目前群組的資料夾在線狀態；同 Wi-Fi 下自動以 mDNS/UDP 搜尋 Mac 與 Android 設備。

### 1.3 介面按鈕位置、產出現象與安全機制

| 元件名稱 | 畫面實際位置 | 用途與目的 | 操作方式 | 產出之現象與安全機制 |
| :--- | :--- | :--- | :--- | :--- |
| **全局健康狀態** | 頂部主標題左側 | 顯示目前系統整體同步狀態 | 自動監控，無須操作 | 綠燈「全部正常」；端點離線、檔案衝突或大量刪除時轉為黃燈「警告」。 |
| **大量刪除防護攔截** | 頂部標題下方（僅異常時出現） | 防止誤刪或勒索軟體一瞬間清空檔案 | 點擊卡片右側「**審核並確認**」 | 單次刪除超過 25 個檔案或佔比 > 25% 時自動攔截並暫停同步。 |
| **追蹤檔案數卡片** | 數據指標區第 1 格 | 即時呈現納入同步監控的檔案總量 | 唯讀顯示 | 標註「SHA-256 即時追蹤」，每次檔案變更均即時更新數字。 |
| **最近完整驗證卡片** | 數據指標區第 2 格 | 追蹤上次執行深層 SHA-256 比對時間 | 唯讀顯示 | 顯示「無異常」或「發現 X 個疑似損毀」提醒處理。 |

## 第二章：差異預覽 (Diff Preview)

### 2.1 頁面功能定位與目的
在檔案寫入目標磁碟前，「差異預覽」提供無風險的**模擬對帳試跑（Dry-Run）**，讓您預先檢視將被複製、更名或刪除的項目清單。

### 2.2 【零基礎新手教學：手把手操作程序】
- **【步驟 1：點擊執行試跑模擬】**：在頂部卡片左側點擊藍色「執行試跑模擬」按鈕。按鈕轉為「模擬計算中...」，在記憶體中比對差異，不修改磁碟檔案。
- **【步驟 2：核對變更清單與符號】**：下方展開變更清單：綠色 `+`（新增複製）、藍色 `➔`（智慧更名）、紅色 `−`（刪除，優先移入資源回收筒）。
- **【步驟 3：點擊確定執行同步】**：確認清單無誤後，點擊右下角「確定執行同步」按鈕，將變更寫入磁碟，完成後頂部彈出 Toast 提示。

### 2.3 介面按鈕位置、產出現象與安全機制

| 按鈕 / 元件名稱 | 畫面實際位置 | 用途與目的 | 操作方式 | 產出之現象與安全機制 |
| :--- | :--- | :--- | :--- | :--- |
| **執行試跑模擬** | 頂部主卡片左側（藍色按鈕） | 模擬比對所有端點差異 | 點擊按鈕 | 按鈕轉為「模擬計算中...」，完成後展開預覽清單。 |
| **確定執行同步** | 模擬清單右下方 | 將核對過的變更寫入目標磁碟 | 點擊確認同步 | 啟動同步作業，頂部彈出同步成功快顯提示。 |

> **預覽符號說明**：
> - 🟢 **`+` (綠色圖示)**：預計新增或複製的檔案。
> - 🔵 **`➔` (藍色圖示)**：預計在目標端點重新命名的檔案。
> - 🔴 **`−` (紅色圖示)**：預計刪除的檔案（**安全保證：一律先移入 Windows 資源回收筒，絕不硬刪**）。

## 第三章：資料夾 (Folders)

### 3.1 頁面功能定位與多資料夾同步群組 (Sync Groups)
「資料夾」是設定同步目標的核心基地。SyncNexus 採用**「同步群組（Folder Groups）」架構模型**：
- **支援多任務獨立同步**：可同時建立多組獨立同步群組（如工作、家庭照片、個人檔案）。
- **全管線與排程隔離**：每個群組擁有專屬端點與 SQLite 狀態庫，大檔案同步絕不卡頓其他群組！

### 3.2 【零基礎新手教學：手把手操作程序】
- **【步驟 1：建立與切換同步群組】**：
  1. 點擊頂部「**＋ 新增群組**」，輸入名稱並選擇代表圖示後儲存。
  2. 點擊不同群組標籤（Chips）即可隨時切換。
  3. 點擊「**✎ 編輯同步群組**」可重新命名或刪除群組（實體檔案保留於磁碟）。
- **【步驟 2：點擊加入資料夾按鈕】**：在頁面底部點擊「**加入資料夾...**」，打開 Windows 檔案總管選取對話框（每個群組至少需加入 2 個資料夾）。
- **【步驟 3：依指引選取 5 大儲存位置】**：
  1. **電腦本機資料夾**：打開檔案總管 ➔ 點擊左側「文件」或進入 `C:` 槽選取目錄。
  2. **OneDrive 雲端硬碟**：打開檔案總管 ➔ 點擊左側「OneDrive」➔ 選取要同步的資料夾。
  3. **Google 雲端硬碟 (Google Drive)**：打開檔案總管 ➔ 點擊左側「Google Drive」➔「我的雲端硬碟」➔ 選取目錄。
  4. **iCloud 雲碟 (Windows 版)**：打開檔案總管 ➔ 點擊左側「iCloud 雲碟」➔ 選取目錄。
  5. **外接隨身碟 / 行動硬碟 (USB)**：插上隨身碟 ➔ 打開檔案總管 ➔ 點選隨身碟磁碟代號（如 `D:` 或 `E:`）➔ 選取目錄（**強烈建議格式化為 ExFAT**）。
- **【步驟 4：更換或移除端點】**：路徑搬移時點擊「**更換資料夾...**」；解除同步點擊「**移除...**」（僅解除關聯，絕不刪除實體檔案）。

### 3.3 介面按鈕位置、產出現象與安全機制

| 按鈕 / 元件名稱 | 畫面實際位置 | 用途與目的 | 操作方式 | 產出之現象與安全機制 |
| :--- | :--- | :--- | :--- | :--- |
| **＋ 新增群組** | 頂部同步群組列右側 | 建立新的多向同步群組 | 點擊並輸入名稱、選取圖示 | 頂部新增群組標籤，自動切換至新群組空白狀態。 |
| **✎ 編輯同步群組** | 目前群組資訊卡片右側 | 修改名稱、圖示或刪除群組 | 點擊開啟編輯彈窗 | 支援更名；刪除時安全脫鉤，磁碟內實體檔案完整保留。 |
| **加入資料夾...** | 列表底部藍色按鈕 | 將新目錄加入同步網絡 | 點擊並於檔案總管中選取目錄 | 自動寫入 `.syncnexus-endpoint` 專屬 UUID 防偽檔。 |

## 第四章：衝突 (Conflicts)

### 4.1 頁面功能定位與目的
當離線狀態下於兩台裝置同時編輯同一個檔案時，SyncNexus 採用**「絕不覆蓋」原則**，將衝突檔案另存為 `檔名 (conflict ...)`, 集中在此頁供您比對與決定。

### 4.2 【零基礎新手教學：手把手操作程序】
- **【步驟 1：察看側欄衝突警示紅標】**：兩端離線同時編輯時，側邊欄「衝突」圖示亮起紅色數字徽章，點擊進入管理。
- **【步驟 2：左右並列對照兩份版本】**：左欄為「目前主要版本」，右欄為「來自端點版本」（標註綠色「較新」標籤），列出檔案大小、修改時間與來源端點。
- **【步驟 3：在檔案總管中打開比對】**：點擊「在檔案總管中顯示」，定位檔案並以文字編輯器比對。
- **【步驟 4：點擊仲裁按鈕完成解決】**：
  - 點擊左側「**保留此版本**」：以主要版本為標準推播至各端點，衝突副本安全歸檔。
  - 點擊右側「**改用此版本**」：採用衝突副本取代主要檔案，舊版本自動存入「舊版本庫」備份。

### 4.3 介面按鈕位置、產出現象與安全機制

| 按鈕 / 元件名稱 | 畫面實際位置 | 用途與目的 | 操作方式 | 產出之現象與安全機制 |
| :--- | :--- | :--- | :--- | :--- |
| **保留此版本** | 左側「目前主要版本」卡片下方 | 決定採用主要版本作為標準版本 | 點擊按鈕 | 主要版本維持現狀並推播至其他端點，衝突副本安全歸檔。 |
| **改用此版本** | 右側「衝突副本版本」卡片下方 | 決定以衝突副本覆蓋為標準版本 | 點擊按鈕 | 衝突副本扶正為正式檔案，舊主要版本自動移至「舊版本庫」備份。 |
| **在檔案總管中顯示** | 兩側版本卡片內均有配置 | 在 Windows 檔案總管中定位檔案 | 點擊按鈕 | 自動開啟檔案總管並反白選取該檔案，方便比對。 |

## 第五章：舊版本 (Versions)

### 5.1 頁面功能定位與目的
每當檔案被修改覆寫或同步取代時，被替換的舊版本會妥善儲存於 `.syncnexus-history` 目錄中，隨時可一鍵還原。

### 5.2 【零基礎新手教學：手把手操作程序】
- **【步驟 1：設定歷史保留天數】**：在頂部卡片「歷史保留期限」下拉選單中，選取保留時間（7天 / 30天 / 90天 / 永久），系統自動清理逾期檔案。
- **【步驟 2：搜尋目標歷史檔案】**：在右上角搜尋框中輸入檔名關鍵字，即時過濾匹配版本。
- **【步驟 3：一鍵還原救回檔案】**：在目標歷史項目右側點擊「**還原**」按鈕；檔案立即覆寫回原目錄並在 2 秒內同步更新至所有端點。
- **【步驟 4：空間清理（選用）】**：點擊「清理過期版本」立即釋放空間；點擊「清空全部」徹底清空歷史備份（絕不影響正在使用的正式檔案）。

### 5.3 介面按鈕位置、產出現象與安全機制

| 按鈕 / 元件名稱 | 畫面實際位置 | 用途與目的 | 操作方式 | 產出之現象與安全機制 |
| :--- | :--- | :--- | :--- | :--- |
| **歷史保留期限選單** | 頂部卡片右側下拉選單 | 設定舊版本在硬碟的最長留存期 | 點選：7天/30天/90天/永久 | 超過天數的舊版本於背景自動清理釋放空間。 |
| **清理過期版本** | 「歷史保留期限選單」右側按鈕 | 手動清除已逾期的歷史舊檔 | 點擊按鈕 | 即時釋放逾期檔案佔用空間，並更新上方容量統計。 |

## 第六章：驗證紀錄 (Verification)

### 6.1 頁面功能定位與目的
利用 **SHA-256 雜湊演算法**對所有端點的所有檔案進行逐 Byte 深度校驗，杜絕檔案傳輸不全或硬碟隱性損壞（Silent Bit-rot）。

### 6.2 【零基礎新手教學：手把手操作程序】
- **【步驟 1：啟動深層完整驗證】**：在中央卡片右側點擊藍色「立即執行完整驗證」按鈕。系統在背景計算所有檔案的 SHA-256 雜湊值。
- **【步驟 2：檢視驗證結果報告】**：驗證完畢後更新「最近完整驗證」時間。一致時顯示綠色徽章「全部正常」；若有檔案損毀則條列清單。
- **【步驟 3：一鍵修復受損檔案】**：
  - 點擊「**從其他端點修復**」：從健康端點下載乾淨副本覆寫修復，受損檔案先備份進歷史庫後修復。
  - 點擊「**接受目前內容**」：確認變更為預期結果，重新計算基準雜湊值解除警報。

### 6.3 介面按鈕位置、產出現象與安全機制

### 7.1 頁面功能定位與目的
個人化同步參數、黑名單排除規則、語系切換與開機自啟動設定。

### 7.2 【零基礎新手教學：手把手操作程序】
- **【步驟 1：挑選衝突處理原則】**：單選「保留兩份，由我挑選（推薦，預設）」或「自動採用較新，舊的存進舊版本」。
- **【步驟 2：自訂排除規則開關】**：勾選排除 `node_modules`、`.git`、資料庫暫存檔（`-wal`, `-shm`），被排除項目不會被傳輸。
- **【步驟 3：設定語系與開機啟動】**：下拉選單切換 6 國語言；開啟「開機自動啟動」，登入 Windows 時自動於系統匣常駐。
- **【步驟 4：檢視日誌與說明】**：點擊「開啟日誌檔案」於記事本中檢視同步日誌；點擊「使用說明指引」重新開啟新手導覽。

## 總結：日常安心使用守則

1. **放鬆工作，免手動按鍵**：只要端點均呈現「在線」，在任一資料夾內存檔或改名，2 秒內所有端點自動完成同步。
2. **有疑慮先「試跑模擬」**：在大批搬移或重整檔案前，先到「差異預覽」按一下「執行試跑模擬」，萬無一失。
3. **誤刪檔案免驚慌**：先翻 Windows「資源回收筒」；若已被清理，直接進「舊版本」頁面點擊「還原」，資料永遠都在！
