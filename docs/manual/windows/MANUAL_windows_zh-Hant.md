# SyncNexus 操作使用手冊 — Windows 完整指南

> **適用平台**：Windows 10 / Windows 11 (64-bit)  
> **核心設計原則**：本機優先（Local-First）、零雲端伺服器依賴、資源回收筒先行（Recycle Bin First）

---

## 頁首控制列功能說明

在 Windows 視窗頂部，配置了全域導覽列：
- **語系切換選單**：支援 6 種語言切換，選取後整套介面即時變更。
- **操作說明手冊 (📖)**：直接在應用程式內部以原生對話框展開本手冊，免聯網、不開啟瀏覽器跳出。
- **隱私權政策 (🛡️)**：呈現純本機同步的資料隱私承諾。

## 第一章：概覽 (Overview)

### 1.1 頁面功能定位與目的
「概覽」是 Windows 使用者的整體健康儀表板。呈現同步端點在線狀態、監控檔案總量、上次 SHA-256 驗證時間與舊版本佔用容量。

### 1.2 功能與按鈕說明
- **全局健康狀態**：綠燈「全部正常」或黃燈「警告 / 離線 / 衝突」。
- **大量刪除防護攔截**：若單次刪除超過 25 個檔案或佔比 > 25%，系統自動暫停同步並出現「審核並確認」提示卡片，防止誤刪。
- **追蹤檔案數**：即時統計納入監控的檔案數量。
- **最近完整驗證**：顯示上次 SHA-256 深層逐位元校驗時間，若有檔案損毀則出現警示。
- **舊版本容量**：顯示歷史版本庫所佔用之硬碟大小及自動清理保留期。
- **端點狀態卡片**：列出本機、OneDrive、Google Drive、iCloud 及外接磁碟（如 `D:`）之在線狀態與 ExFAT 相容標記。
- **同 Wi-Fi 局域網直連**：以標準 mDNS/UDP 自動探索同一網路內的 Mac 與 Android 裝置。

## 第二章：差異預覽 (Diff Preview)

### 2.1 頁面功能定位與目的
在檔案寫入目標磁碟前，「差異預覽」提供無風險的模擬對帳（Dry-Run），讓您預先檢視將被複製、改名或刪除的項目清單。

### 2.2 功能與按鈕說明
- **執行試跑模擬**：點擊觸發模擬運算，列出即將執行的檔案變更清單，附帶新增（+）、更名（➔）、刪除（−）圖示。
- **確定執行同步**：預覽確認安全無誤後點擊，將變更一次性寫入各目標磁碟。
- **安全快顯提示**：當模擬完成或偵測到潛在風險時，視窗頂部會彈出快顯 Toast 提示說明。

## 第三章：資料夾 (Folders)

### 3.1 頁面功能定位與目的
設定並管理參與同步的各個資料夾（需加入至少 2 個端點以啟用同步）。

### 3.2 5 大儲存位置接地氣加入指南
點擊「**加入資料夾...**」，透過 Windows 檔案總管選取目錄：
1. **電腦本機資料夾**：打開「檔案總管」，點擊左側「文件」或進入 `C:` 槽選取目錄。
2. **OneDrive 雲端硬碟**：打開「檔案總管」，點擊左側「OneDrive」，選取要同步的資料夾。
3. **Google 雲端硬碟 (Google Drive)**：打開「檔案總管」，點擊左側「Google Drive」➔「我的雲端硬碟」，選取要同步的目錄。
4. **iCloud 雲碟 (Windows 版)**：打開「檔案總管」，點擊左側「iCloud 雲碟」，選取目錄。
5. **外接式隨身碟 / 行動硬碟 (USB)**：插上隨身碟，打開「檔案總管」，點擊左側「本機」下方的磁碟機代號（如 `D:` 或 `E:`），選取目錄。**強烈建議格式化為 ExFAT**，方便同時與 Mac 跨系統無縫共用！

### 3.3 功能與按鈕說明
- **加入資料夾...**：選取目錄加入同步群組，系統自動寫入 `.syncnexus-endpoint` 專屬 UUID 防偽檔。
- **更換資料夾...**：當磁碟機代號改變或目錄搬移時重新關聯路徑。
- **移除...**：解除該資料夾的同步關係，**絕不刪除資料夾內的實體檔案**。
- **防偽標記鎖定**：若插錯其他隨身碟，標記檔不符時主動呈現「標記檔與此端點不符，已停止傳播」，保護資料不被錯蓋。

## 第四章：衝突 (Conflicts)

### 4.1 頁面功能定位與目的
當離線狀態下於兩台裝置同時編輯同一個檔案時，SyncNexus 採用「絕不覆蓋」原則，將衝突檔案另存為 `檔名 (conflict ...)`, 集中在此頁供您比較。

### 4.2 功能與按鈕說明
- **保留此版本**：維持主要版本，推播至其他端點，衝突副本安全歸檔。
- **改用此版本**：採用帶有綠色「較新」標籤的衝突副本覆蓋為主要檔案，原版本退入歷史庫。
- **在檔案總管中顯示**：直接打開 Windows 檔案總管並反白選取該檔案，方便以比對工具比對內容。

---

## 第五章：舊版本 (Versions)

### 5.1 頁面功能定位與目的
每當檔案被修改覆寫或同步取代時，被替換的舊版本會妥善儲存於 `.syncnexus-history` 目錄中，隨時可一鍵還原。

### 5.2 功能與按鈕說明
- **歷史保留期限**：下拉選單可選 7天 / 30天 / 90天 / 永久，逾期自動清理。
- **清理過期版本**：立即清除超出保留期的歷史舊檔，釋放硬碟空間。
- **清空全部**：清空所有歷史版本備份（不影響目前正式工作檔案）。
- **搜尋框**：即時以檔名或端點名稱篩選歷史版本。
- **還原 (Restore)**：點擊即可將該歷史版本救回原目錄並自動同步至所有端點。

## 第六章：驗證紀錄 (Verification)

### 6.1 頁面功能定位與目的
利用 SHA-256 演算法對所有端點的所有檔案進行逐 Byte 深度校驗，杜絕檔案傳輸不全或硬碟隱性損壞。

### 6.2 功能與按鈕說明
- **立即執行完整驗證**：啟動全端點 SHA-256 校驗運算。
- **從其他端點修復**：若發現某端點檔案損毀，一鍵從其他健康的端點提取正確複本覆寫修復。
- **接受目前內容**：若變更屬預期內容，更新雜湊基準值解除警報。

## 第七章：設定 (Settings)

### 7.1 頁面功能定位與目的
個人化同步參數、排除清單與開機啟動設定。

### 7.2 功能與按鈕說明
- **衝突處理原則**：
  1. `保留兩份，由我挑選`（預設，推薦）
  2. `自動採用較新，舊的存進舊版本`
- **排除規則**：可自由勾選排除 `node_modules`、`.git`、資料庫暫存檔（`-wal`, `-shm`）。
- **介面語言**：即時切換 6 國語言。
- **開機自動啟動**：登入 Windows 時自動於系統匣常駐執行。
- **開啟日誌檔案**：於記事本中檢視同步日誌。
