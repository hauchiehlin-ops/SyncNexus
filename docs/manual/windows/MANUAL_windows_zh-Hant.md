# SyncNexus 操作使用手冊 — Windows 篇

## 1. 簡介與特色
**SyncNexus for Windows** 是專為 Windows 10 與 Windows 11 所打造的本機優先檔案即時同步軟體。無須上傳雲端伺服器，讓不同磁碟與雲端資料夾永遠保持一致。

* **原生 Windows 體驗**：支援微軟 Fluent UI、系統匣縮小常駐（System Tray）、開機自動啟動與即時通知。
* **跨平台區域直連**：內建雙棧 mDNS（標準 224.0.0.251:5353）與 UDP 廣播，自動發現同 Wi-Fi 內的 Mac 與 Android 裝置。
* **完整安全機制**：同步刪除時自動移至 Windows「資源回收筒」；提供版本歷史備份與衝突雙向保留。

---

## 2. 快速上手：如何加入同步資料夾？

在主畫面點擊「**新增同步端點...**」，選取您準備要同步的目錄：

1. **電腦本機資料夾**：
   - 打開「檔案總管」，點擊左側側邊欄的「文件」或進入 `C:` 槽選取您想要同步的資料夾。
2. **iCloud 雲碟**：
   - 打開「檔案總管」，點擊左側側邊欄的「iCloud 雲碟」圖示，選取準備要同步的資料夾。
3. **Google 雲端硬碟 (Google Drive)**：
   - 打開「檔案總管」，點擊左側側邊欄的「Google Drive」，點擊「我的雲端硬碟」，選取準備要同步的資料夾。
4. **OneDrive 雲端硬碟**：
   - 打開「檔案總管」，點擊左側側邊欄的「OneDrive」，選取準備要同步的資料夾。
5. **外接隨身碟 / 行動硬碟**：
   - 插上外接隨身碟，打開「檔案總管」，點擊左側「本機」下方的隨身硬碟磁碟機代號（如 `D:` 或 `E:`），選取準備要同步的資料夾。格式建議為 **ExFAT**，方便同時與 Mac 互相插拔共用！

---

## 3. 全自動同步與防護

* **即時自動偵測**：任何資料夾內有檔案變更，系統將在 2 秒內自動完成對帳與複製。
* **防覆蓋衝突保護**：離線雙向修改時，自動保留兩邊檔案，並將本端版本另存為帶有時間戳記的衝突副本。
* **安全還原**：刪除檔案優先進入 Windows 資源回收筒；可隨時在「衝突與歷史記錄」視窗還原舊版本。
