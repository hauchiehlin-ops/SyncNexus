# SyncNexus 사용 설명서 — Windows 전체 가이드

> **지원 플랫폼**: Windows 10 / Windows 11 (64-bit)  
> **현재 버전**: 1.2.0 (build 22)  
> **핵심 설계 원칙**: 로컬 우선(Local-First), 클라우드 서버 의존 없음, 휴지통 우선(Recycle Bin First)

---

## 상단 헤더 사용법

Windows 앱 창 맨 위에는 전체 탐색 막대가 있습니다:

```
[ 현재 페이지 제목 ] ------------------------- [ 언어 메뉴 ▾ ] [ 📖 설명서 ] [ 🛡️ 개인정보 ]
```

1. **언어 드롭다운 메뉴**:
   - **위치**: 헤더 오른쪽 위.
   - **용도**: 6개 표시 언어(번체 중국어, 간체 중국어, English, 日本語, 한국어, ภาษาไทย)를 즉시 전환합니다.
   - **사용 방법**: 클릭해 메뉴를 열고 원하는 언어를 선택하면 재시작 없이 앱 전체 언어가 바로 바뀝니다.
2. **사용 설명서 버튼 (📖 아이콘)**:
   - **위치**: 언어 메뉴 오른쪽.
   - **용도**: 이 설명서를 앱 안의 대화상자로 바로 엽니다. 인터넷 연결이 필요 없고 외부 브라우저도 열지 않습니다.
   - **사용 방법**: 클릭해서 열고 언제든 참고하세요. `Esc` 키나 "닫기"를 누르면 작업 화면으로 돌아갑니다.
3. **개인정보 처리방침 버튼 (🛡️ 아이콘)**:
   - **위치**: 설명서 버튼 오른쪽.
   - **용도**: 로컬 우선 동기화의 개인정보 보호 약속과, 클라우드로 전송하지 않는 보호 장치를 설명합니다.

## 1장: 개요 (Overview)

### 1.1 목적
**개요**는 Windows 사용자를 위한 전체 상태 대시보드입니다. 폴더의 온라인/오프라인 상태, 추적 중인 전체 파일 수, 마지막 SHA-256 검증 시각, 이전 버전 사용량, 로컬 네트워크 P2P 검색 결과를 보여 줍니다.

### 1.2 【초보자를 위한 단계별 안내】
- **【1단계: 상단 컨트롤 막대 확인】**: 오른쪽 위의 언어 선택기, "사용 설명서 📖", "개인정보 🛡️" 버튼을 확인하세요. 언제든 눌러서 언어를 바꾸거나 설명서를 볼 수 있습니다.
- **【2단계: 전체 상태 확인】**: 왼쪽 위의 상태 배지는 모두 정상이면 초록색 "모두 정상", 폴더 연결이 끊겼거나 처리 대기 중인 충돌이 있으면 노란색 "경고"로 표시됩니다.
- **【3단계: 대량 삭제 보호 대응】**: 한 번에 25개 초과 또는 25% 초과의 파일이 삭제되면 동기화가 자동으로 멈추고 "검토 후 확인" 배너가 나타납니다. 눌러서 승인하거나 복원하세요.
- **【4단계: 엔드포인트와 LAN P2P 확인】**: 가운데 그리드에 현재 그룹의 모든 폴더 상태가 표시됩니다. 같은 Wi-Fi에 있는 주변 Mac과 Android 기기는 mDNS/UDP로 자동 검색됩니다.

### 1.3 컨트롤, 위치, 안전 장치

| 컨트롤 / 요소 | 화면 위치 | 목적 | 사용 방법 | 기대 결과와 안전 장치 |
| :--- | :--- | :--- | :--- | :--- |
| **전체 상태** | 상단 제목 영역 | 동기화 전반의 건강 상태 | 자동 상시 모니터링 | 초록색 "모두 정상". 연결 끊김, 충돌, 대량 삭제가 있으면 노란색 "경고"로 바뀝니다. |
| **대량 삭제 보호** | 상단 제목 아래 (이상 시에만 표시) | 실수로 인한 삭제나 랜섬웨어로 인한 파일 소실 방지 | "**검토 후 확인**" 클릭 | 한 번에 25개 초과 또는 25% 초과의 파일이 삭제되면 동기화를 차단하고 일시 중지합니다. |
| **추적 중인 파일** | 통계 타일 #1 | 모든 엔드포인트에서 추적하는 파일 총수 | 읽기 전용 | "실시간 SHA-256 추적"이 표시되며 파일이 바뀌면 동적으로 갱신됩니다. |
| **마지막 정밀 검증** | 통계 타일 #2 | 마지막 SHA-256 무결성 검사 시각 | 읽기 전용 | "이상 없음" 또는 "손상 의심 X건"을 표시해 조치를 안내합니다. |
| **이전 버전** | 통계 타일 #3 | 버전 보관함이 차지하는 저장 공간 | 읽기 전용 | 예: "24.5 MB · 30일 보관, 언제든 복원 가능". |
| **엔드포인트 상태 카드** | 가운데 그리드 영역 | 동기화 중인 각 폴더의 상태와 경로 | 카드 정보 확인 | 초록색 "온라인" 또는 노란색 "오프라인"으로 표시. 외장 드라이브에는 "ExFAT"이 표시됩니다. |
| **LAN P2P 직접 연결 카드** | 하단 네트워크 영역 | Wi-Fi의 Mac, PC, Android 기기 검색 | 지속적으로 검색 | 발견된 기기 이름과 초록색 "온라인" 칩을 표시하며 직접 P2P 전송이 가능합니다. |

## 2장: 차이 미리보기 (Diff Preview)

### 2.1 목적
변경 사항을 대상 디스크에 적용하기 전에, **차이 미리보기**가 위험 없는 **드라이 런(시험 실행)** 을 수행하여 예정된 복사, 이름 변경, 삭제를 미리 보여 줍니다.

### 2.2 【초보자를 위한 단계별 안내】
- **【1단계: "시험 계산 실행" 클릭】**: 왼쪽 위 카드의 파란색 "시험 계산 실행" 버튼을 누릅니다. 계산하는 동안 버튼이 "시뮬레이션 중..."으로 바뀌며, 디스크의 파일은 건드리지 않고 메모리에서만 차이를 계산합니다.
- **【2단계: 미리보기 기호 확인】**: 아래에 목록이 펼쳐집니다. 초록색 `+`(새 복사), 파란색 `➔`(스마트 이름 변경), 빨간색 `−`(삭제, 먼저 휴지통으로 이동).
- **【3단계: "확인 후 동기화" 클릭】**: 목록을 확인한 뒤 오른쪽 아래의 "확인 후 동기화"를 누르면 모든 디스크에 변경 사항이 적용되고, 위쪽에 완료를 알리는 토스트 알림이 나타납니다.

### 2.3 컨트롤, 위치, 안전 장치

| 버튼 / 컨트롤 | 화면 위치 | 목적 | 사용 방법 | 기대 결과와 안전 장치 |
| :--- | :--- | :--- | :--- | :--- |
| **시험 계산 실행** | 메인 카드 왼쪽 위 (파란색 버튼) | 모든 엔드포인트 간 대조를 시뮬레이션 | 버튼 클릭 | "시뮬레이션 중..."으로 바뀐 뒤 아래에 변경 미리보기 목록이 표시됩니다. |
| **확인 후 동기화** | 미리보기 목록 오른쪽 아래 | 확인한 변경 사항을 대상 디스크에 기록 | 클릭하여 확정 | 동기화 엔진이 시작되고 위쪽의 토스트가 성공을 알려 줍니다. |

> **미리보기 기호**:
> - 🟢 **`+` (초록색)**: 추가되거나 복사될 예정인 파일.
> - 🔵 **`➔` (파란색)**: 로컬에서 이름이 바뀔 예정인 파일.
> - 🔴 **`−` (빨간색)**: 삭제될 예정인 파일 (**보장: 먼저 Windows 휴지통으로 이동하며 영구 삭제하지 않습니다**).

## 3장: 폴더 (Folders)

### 3.1 목적과 다중 폴더 동기화 그룹
**폴더** 탭에서는 **폴더 그룹 구조**로 동기화 네트워크를 설정하고 관리합니다:
- **여러 작업의 독립 동기화**: 업무, 가족 사진, 개인 재무처럼 서로 독립적인 동기화 그룹을 동시에 여러 개 만들 수 있습니다.
- **독립된 파이프라인과 합의**: 그룹마다 자체 폴더와 SQLite 합의 저장소를 가지므로, 한 그룹의 대용량 동기화가 다른 그룹을 멈추게 하지 않습니다!

### 3.2 【초보자를 위한 단계별 안내】
- **【1단계: 동기화 그룹 만들기와 전환】**:
  1. 위쪽의 "**+ 새 그룹**"을 눌러 이름을 입력하고 아이콘을 고른 뒤 저장합니다.
  2. 그룹 칩을 눌러 사용할 그룹을 바꿉니다.
  3. "**✎ 동기화 그룹 편집**"을 누르면 이름을 바꾸거나 그룹을 삭제할 수 있습니다 (디스크의 실제 파일은 그대로 남습니다).
- **【2단계: "폴더 추가..." 클릭】**: 아래쪽의 "**폴더 추가...**"를 눌러 Windows 파일 탐색기를 엽니다 (그룹마다 폴더가 2개 이상 필요).
- **【3단계: 5가지 저장 위치 중에서 선택】**:
  1. **로컬 PC 폴더**: 파일 탐색기 열기 ➔ "문서"를 누르거나 `C:` 드라이브로 이동 ➔ 폴더 선택.
  2. **OneDrive**: 파일 탐색기 열기 ➔ 사이드바의 "OneDrive" 클릭 ➔ 폴더 선택.
  3. **Google Drive**: 파일 탐색기 열기 ➔ "Google Drive" ➔ "내 드라이브" ➔ 디렉터리 선택.
  4. **iCloud Drive (Windows)**: 파일 탐색기 열기 ➔ 사이드바의 "iCloud Drive" 클릭 ➔ 디렉터리 선택.
  5. **외장 USB 플래시 / 휴대용 드라이브**: USB 드라이브 연결 ➔ 파일 탐색기 열기 ➔ 드라이브 문자(예: `D:` 또는 `E:`) 클릭 ➔ 폴더 선택 (**ExFAT 형식을 강력히 권장**).
- **【4단계: 다시 연결 또는 삭제】**: 폴더를 옮겼다면 "**폴더 변경...**"을 누릅니다. "**삭제...**"를 누르면 연결이 해제됩니다 (연결을 해제해도 실제 파일은 삭제되지 않습니다).

### 3.3 컨트롤, 위치, 안전 장치

| 컨트롤 / 요소 | 화면 위치 | 목적 | 사용 방법 | 기대 결과와 안전 장치 |
| :--- | :--- | :--- | :--- | :--- |
| **+ 새 그룹** | 상단 동기화 그룹 막대 | 새 독립 동기화 그룹 만들기 | 클릭 후 이름과 아이콘 입력 | 새 그룹 칩이 나타나고 빈 상태로 자동 전환됩니다. |
| **✎ 동기화 그룹 편집** | 사용 중인 그룹 정보 오른쪽 | 이름 변경, 아이콘 변경, 그룹 삭제 | 클릭하여 편집 시트 열기 | 이름 변경을 지원하며, 삭제는 연결만 해제하고 실제 파일은 건드리지 않습니다. |
| **폴더 추가...** | 폴더 목록 아래 (파란색 버튼) | 동기화 네트워크에 디렉터리 추가 | 클릭 후 탐색기에서 선택 | 고유한 `.syncnexus-endpoint` UUID 마커 파일을 기록합니다. |
| **폴더 변경...** | 각 엔드포인트 카드 오른쪽 | 드라이브 문자나 경로가 바뀌었을 때 다시 연결 | 클릭 후 새 경로 선택 | 마커를 확인하고 연결을 자동으로 복구합니다. |
| **삭제...** | 각 엔드포인트 카드 오른쪽 | 동기화 그룹에서 폴더 연결 해제 | 클릭 후 대화상자에서 확인 | 동기화에서 연결을 해제하며 **실제 파일은 삭제하지 않습니다**. |
| **마커 보호** | 엔드포인트 카드 상태 영역 | 잘못된 USB 드라이브 연결 방지 | 지속적인 자동 검증 | 잘못된 드라이브가 연결되면 "마커가 일치하지 않아 전파를 중단했습니다"라고 표시하고 자동으로 격리합니다! |

## 4장: 충돌 (Conflicts)

### 4.1 목적
두 기기에서 오프라인 상태로 동시에 편집이 일어나면 SyncNexus는 엄격한 **덮어쓰기 금지 정책**을 적용해, 충돌한 파일을 `파일명 (conflict ...)` 으로 저장하고 이곳에 모아 나란히 비교하고 해결할 수 있게 합니다.

### 4.2 【초보자를 위한 단계별 안내】
- **【1단계: 빨간 충돌 배지 확인】**: 오프라인 동시 편집이 발생하면 사이드바의 "충돌" 아이콘에 빨간 배지가 나타납니다. 눌러서 엽니다.
- **【2단계: 2열 카드 확인】**: 왼쪽 카드는 "현재 버전", 오른쪽 카드는 "엔드포인트 버전"(초록색 "최신" 배지 포함)이며, 크기, 수정 날짜, 출처가 표시됩니다.
- **【3단계: 파일 탐색기에서 표시】**: "파일 탐색기에서 표시"를 누르면 해당 파일이 선택되어, 텍스트 편집기로 비교할 수 있습니다.
- **【4단계: 처리 방법 선택】**:
  - 왼쪽 "**이 버전 유지**": 기본 파일을 유지하고 모든 엔드포인트에 반영하며, 충돌 사본은 보관합니다.
  - 오른쪽 "**이 버전 사용**": 충돌 사본을 공식 기본 파일로 승격하고, 이전 기본 파일은 이전 버전에 백업합니다.

### 4.3 컨트롤, 위치, 안전 장치

| 버튼 / 컨트롤 | 화면 위치 | 목적 | 사용 방법 | 기대 결과와 안전 장치 |
| :--- | :--- | :--- | :--- | :--- |
| **이 버전 유지** | 왼쪽 "현재 버전" 카드 아래 | 기본 파일을 유지하여 충돌 해결 | 버튼 클릭 | 기본 파일이 정식 버전으로 남아 다른 엔드포인트에 전파되고, 충돌 사본은 안전하게 보관됩니다. |
| **이 버전 사용** | 오른쪽 "엔드포인트 버전" 카드 아래 | 들어온 사본을 채택하여 충돌 해결 | 버튼 클릭 | 충돌 사본이 정식 파일이 되고, 이전 기본 파일은 이전 버전에 백업됩니다. |
| **파일 탐색기에서 표시** | 두 버전 카드 안 | 실제 파일을 파일 탐색기에서 표시 | 버튼 클릭 | 파일 탐색기가 열리고 파일이 선택되어, 텍스트를 직접 확인하거나 차이를 비교할 수 있습니다. |
| **충돌 없음 상태** | 모두 해결되었을 때의 빈 화면 | 모든 파일이 일치함을 확인 | 읽기 전용 | 초록색 체크 표시와 "처리 대기 중인 충돌이 없습니다. 모든 파일이 동일합니다"를 보여 줍니다. |

## 5장: 이전 버전 (Versions)

### 5.1 목적
파일이 덮어쓰이거나 동기화될 때마다 교체된 버전이 `.syncnexus-history` 에 보관되어, 언제든 한 번의 클릭으로 되돌릴 수 있습니다.

### 5.2 【초보자를 위한 단계별 안내】
- **【1단계: 보관 정책 설정】**: 위쪽 드롭다운에서 보관 기간(7 / 30 / 90일 또는 영구)을 고릅니다. 기간이 지난 파일은 백그라운드에서 자동 정리됩니다.
- **【2단계: 원하는 버전 검색】**: 오른쪽 위 검색창에 파일 이름 키워드를 입력하면 버전이 바로 걸러집니다.
- **【3단계: "복원"을 눌러 파일 되돌리기】**: 버전 카드의 "**복원**"을 누르면 파일이 즉시 작업 디렉터리로 돌아오고 2초 안에 모든 엔드포인트에 동기화됩니다.
- **【4단계: 저장 공간 관리 (선택)】**: "만료 항목 지금 정리"로 오래된 백업을 지우거나, "모두 지우기"로 확인 후 보관함을 비웁니다 (사용 중인 파일에는 영향이 없습니다).

### 5.3 컨트롤, 위치, 안전 장치

| 버튼 / 컨트롤 | 화면 위치 | 목적 | 사용 방법 | 기대 결과와 안전 장치 |
| :--- | :--- | :--- | :--- | :--- |
| **보관 정책 메뉴** | 상단 카드의 "자동 정리" 오른쪽 | 최대 보관 기간 설정 | 7 / 30 / 90일 또는 영구 선택 | 지정한 일수가 지난 파일은 백그라운드에서 자동 삭제됩니다. |
| **만료 항목 지금 정리** | 보관 메뉴 옆 | 만료된 버전을 즉시 수동 삭제 | 버튼 클릭 | 디스크 공간을 즉시 확보하고 상단 통계를 갱신합니다. |

| **복원** | 각 버전 기록 오른쪽 | 선택한 버전을 폴더로 되돌림 | "**복원**" 클릭 | 선택한 버전으로 현재 파일을 덮어쓰고 모든 엔드포인트에 동기화합니다. |

## 6장: 검증 (Verification)

### 6.1 목적
SyncNexus는 **SHA-256 암호화 해시 알고리즘**으로 모든 엔드포인트의 모든 바이트를 검증하여, 불완전한 전송과 디스크의 조용한 손상(비트 부패, bit-rot)을 막습니다.

### 6.2 【초보자를 위한 단계별 안내】
- **【1단계: 정밀 검증 시작】**: 가운데 카드의 파란색 "지금 검증 시작" 버튼을 누릅니다. 엔진이 백그라운드에서 모든 엔드포인트의 SHA-256 해시를 계산합니다.
- **【2단계: 검증 보고서 확인】**: 완료되면 "마지막 정밀 검증" 시각이 갱신됩니다. 모두 일치하면 초록색 "모두 정상" 배지가, 손상이 발견되면 손상된 파일 목록이 표시됩니다.
- **【3단계: 손상된 파일 복구】**:
  - "**다른 엔드포인트에서 복구**" 클릭: 정상 엔드포인트에서 비트 단위로 정확한 사본을 받아 손상된 파일을 교체합니다 (손상된 파일은 먼저 기록에 백업됩니다).
  - "**현재 내용 수락**" 클릭: 의도한 변경이라면 기준 해시를 다시 계산하고 경고를 지웁니다.

### 6.3 컨트롤, 위치, 안전 장치

| 버튼 / 컨트롤 | 화면 위치 | 목적 | 사용 방법 | 기대 결과와 안전 장치 |
| :--- | :--- | :--- | :--- | :--- |
| **지금 검증 시작** | 가운데 카드 오른쪽 (파란색 버튼) | SHA-256 정밀 해시 계산 시작 | "**지금 검증 시작**" 클릭 | 백그라운드에서 계산하며 끝나면 시각과 이상 목록을 갱신합니다. |
| **다른 엔드포인트에서 복구** | 손상된 파일이 발견되면 표시 | 정상 엔드포인트에서 올바른 파일 받기 | 클릭하여 복구 | 정상 엔드포인트에서 원본 사본을 받고, 교체된 손상 파일은 기록에 보존됩니다. |
| **현재 내용 수락** | 손상된 파일이 발견되면 표시 | 의도한 변경이면 기준 해시 갱신 | 클릭하여 수락 | 합의 저장소의 기준 해시를 다시 계산하고 경고 배지를 지웁니다. |

## 7장: 설정 (Settings)

### 7.1 목적
동기화 환경설정, 제외 필터, 언어 전환, 시작 시 자동 실행을 설정합니다.

### 7.2 【초보자를 위한 단계별 안내】
- **【1단계: 충돌 정책 선택】**: "둘 다 유지하고 직접 선택(권장)" 또는 "최신 버전 우선, 이전 버전은 이전 버전 목록에 저장" 중에서 고릅니다.
- **【2단계: 제외 스위치 설정】**: `node_modules`, `.git`, SQLite 잠금 파일(`-wal`, `-shm`)의 제외 스위치를 켜거나 끕니다. 제외된 항목은 전송되지 않습니다.
- **【3단계: 언어와 시작 설정】**: 6개 표시 언어 중에서 선택합니다. "로그인 시 시작"을 켜면 Windows 시스템 트레이에서 조용히 시작합니다.
- **【4단계: 로그와 가이드 보기】**: "로그 파일 열기"를 누르면 메모장에서 동기화 진단 정보를 볼 수 있고, "시작 가이드"에서 초보자용 안내를 다시 볼 수 있습니다.

### 7.3 컨트롤, 위치, 안전 장치

| 설정 항목 | 화면 위치 | 목적 | 옵션과 사용 방법 | 기대 결과와 안전 장치 |
| :--- | :--- | :--- | :--- | :--- |
