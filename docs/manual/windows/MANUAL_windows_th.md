# คู่มือการใช้งาน SyncNexus — คู่มือฉบับสมบูรณ์สำหรับ Windows

> **แพลตฟอร์มที่รองรับ**: Windows 10 / Windows 11 (64-bit)  
> **เวอร์ชันปัจจุบัน**: 1.2.0 (build 22)  
> **หลักการออกแบบ**: ข้อมูลอยู่ในเครื่องเป็นหลัก (Local-First), ไม่พึ่งพาเซิร์ฟเวอร์คลาวด์, ถังรีไซเคิลมาก่อน (Recycle Bin First)

---

## แถบส่วนหัวด้านบน

ที่ด้านบนสุดของหน้าต่างแอปบน Windows มีแถบนำทางหลักดังนี้:

```
[ ชื่อหน้าปัจจุบัน ] ------------------------- [ เมนูภาษา ▾ ] [ 📖 คู่มือ ] [ 🛡️ ความเป็นส่วนตัว ]
```

1. **เมนูแบบเลื่อนลงสำหรับเลือกภาษา**:
   - **ตำแหน่ง**: มุมขวาบนของส่วนหัว
   - **หน้าที่**: สลับระหว่างภาษาของอินเทอร์เฟซ 6 ภาษาได้ทันที (จีนตัวเต็ม, จีนตัวย่อ, English, 日本語, 한국어, ภาษาไทย)
   - **วิธีใช้**: คลิกเพื่อเปิดเมนู เลือกภาษาที่ต้องการ แอปทั้งหมดจะเปลี่ยนภาษาทันทีโดยไม่ต้องรีสตาร์ต
2. **ปุ่มคู่มือการใช้งาน (ไอคอน 📖)**:
   - **ตำแหน่ง**: ทางขวาของเมนูภาษา
   - **หน้าที่**: เปิดคู่มือนี้ในกล่องโต้ตอบภายในแอปโดยตรง ไม่ต้องใช้อินเทอร์เน็ตและไม่เปิดเบราว์เซอร์ภายนอก
   - **วิธีใช้**: คลิกเพื่อเปิดและอ่านได้ทุกเมื่อ กด `Esc` หรือ "ปิด" เพื่อกลับไปทำงานต่อ
3. **ปุ่มนโยบายความเป็นส่วนตัว (ไอคอน 🛡️)**:
   - **ตำแหน่ง**: ทางขวาของปุ่มคู่มือ
   - **หน้าที่**: อธิบายคำมั่นสัญญาด้านความเป็นส่วนตัวของการซิงค์ที่เน้นข้อมูลในเครื่อง และการป้องกันที่ไม่ส่งข้อมูลขึ้นคลาวด์

## บทที่ 1: ภาพรวม (Overview)

### 1.1 วัตถุประสงค์
**ภาพรวม** คือแดชบอร์ดสุขภาพโดยรวมสำหรับผู้ใช้ Windows แสดงสถานะออนไลน์/ออฟไลน์ของโฟลเดอร์ จำนวนไฟล์ที่ติดตามทั้งหมด เวลาที่ตรวจสอบ SHA-256 ครั้งล่าสุด พื้นที่ที่เวอร์ชันเก่าใช้ และการค้นหาอุปกรณ์ P2P ในเครือข่ายภายใน

### 1.2 【คู่มือสำหรับผู้เริ่มต้น: ทำตามทีละขั้นตอน】
- **【ขั้นตอนที่ 1: ดูแถบควบคุมด้านบน】**: ดูที่มุมขวาบน จะมีตัวเลือกภาษา ปุ่ม "คู่มือการใช้งาน 📖" และ "ความเป็นส่วนตัว 🛡️" คลิกได้ทุกเมื่อเพื่อเปลี่ยนภาษาหรืออ่านคู่มือ
- **【ขั้นตอนที่ 2: ดูสถานะสุขภาพโดยรวม】**: ป้ายสถานะที่มุมซ้ายบนจะแสดง "ปกติทั้งหมด" สีเขียวเมื่อทุกอย่างเรียบร้อย หรือ "คำเตือน" สีเหลืองหากมีโฟลเดอร์ที่ขาดการเชื่อมต่อหรือมีข้อขัดแย้งที่รอจัดการ
- **【ขั้นตอนที่ 3: รับมือกับการป้องกันการลบจำนวนมาก】**: หากมีการลบไฟล์เกิน 25 ไฟล์ หรือเกิน 25% ในครั้งเดียว การซิงค์จะหยุดโดยอัตโนมัติและมีแบนเนอร์ "ตรวจสอบและยืนยัน" ปรากฏขึ้น คลิกเพื่ออนุมัติหรือกู้คืน
- **【ขั้นตอนที่ 4: ดูปลายทางและ LAN P2P】**: ตารางตรงกลางแสดงสถานะของโฟลเดอร์ทั้งหมดในกลุ่มปัจจุบัน ส่วนอุปกรณ์ Mac และ Android ใกล้เคียงบน Wi-Fi เดียวกันจะถูกค้นหาโดยอัตโนมัติผ่าน mDNS/UDP

### 1.3 ตัวควบคุม ตำแหน่ง และมาตรการป้องกัน

| ตัวควบคุม / องค์ประกอบ | ตำแหน่งบนหน้าจอ | หน้าที่และวัตถุประสงค์ | วิธีใช้ | ผลลัพธ์ที่คาดหวังและการป้องกัน |
| :--- | :--- | :--- | :--- | :--- |
| **สถานะสุขภาพโดยรวม** | พื้นที่หัวเรื่องด้านบน | สุขภาพของการซิงค์โดยรวม | เฝ้าระวังอัตโนมัติต่อเนื่อง | สีเขียว "ปกติทั้งหมด" เปลี่ยนเป็นสีเหลือง "คำเตือน" เมื่อมีการขาดการเชื่อมต่อ ข้อขัดแย้ง หรือการลบจำนวนมาก |
| **การป้องกันการลบจำนวนมาก** | ใต้หัวเรื่องด้านบน (แสดงเฉพาะเมื่อผิดปกติ) | ป้องกันการลบโดยไม่ตั้งใจหรือแรนซัมแวร์ล้างข้อมูล | คลิก "**ตรวจสอบและยืนยัน**" | ดักและหยุดการซิงค์ชั่วคราวเมื่อไฟล์ถูกลบเกิน 25 ไฟล์หรือเกิน 25% ในครั้งเดียว |
| **ไฟล์ที่ติดตาม** | การ์ดสถิติ #1 | จำนวนไฟล์ทั้งหมดที่ติดตามในทุกปลายทาง | อ่านอย่างเดียว | แสดง "ติดตาม SHA-256 แบบเรียลไทม์" และอัปเดตแบบไดนามิกเมื่อไฟล์เปลี่ยน |
| **การตรวจสอบเชิงลึกล่าสุด** | การ์ดสถิติ #2 | เวลาของการตรวจสอบความสมบูรณ์ SHA-256 ครั้งล่าสุด | อ่านอย่างเดียว | แสดง "ไม่พบความผิดปกติ" หรือ "สงสัยว่าเสียหาย X ไฟล์" เพื่อให้คุณดำเนินการ |
| **เวอร์ชันเก่า** | การ์ดสถิติ #3 | พื้นที่ที่คลังเวอร์ชันใช้อยู่ | อ่านอย่างเดียว | เช่น "24.5 MB · เก็บ 30 วัน กู้คืนได้ทุกเมื่อ" |
| **การ์ดสถานะปลายทาง** | พื้นที่ตารางตรงกลาง | สถานะและพาธของโฟลเดอร์ที่ซิงค์แต่ละโฟลเดอร์ | ดูข้อมูลบนการ์ด | แสดง "ออนไลน์" สีเขียวหรือ "ออฟไลน์" สีเหลือง ไดรฟ์ภายนอกจะแสดง "ExFAT" |
| **การ์ด LAN P2P โดยตรง** | พื้นที่เครือข่ายด้านล่าง | ค้นหา Mac, PC และอุปกรณ์ Android บน Wi-Fi | ค้นหาต่อเนื่อง | แสดงชื่ออุปกรณ์ที่พบพร้อมป้าย "ออนไลน์" สีเขียว เพื่อถ่ายโอน P2P โดยตรง |

## บทที่ 2: ดูตัวอย่างความต่าง (Diff Preview)

### 2.1 วัตถุประสงค์
ก่อนจะเขียนการเปลี่ยนแปลงลงดิสก์ปลายทาง **ดูตัวอย่างความต่าง** จะทำ **การจำลองการทำงาน (Dry-Run)** ที่ปลอดภัย เพื่อให้คุณดูการคัดลอก การเปลี่ยนชื่อ และการลบที่กำลังจะเกิดขึ้น

### 2.2 【คู่มือสำหรับผู้เริ่มต้น: ทำตามทีละขั้นตอน】
- **【ขั้นตอนที่ 1: คลิก "เริ่มจำลองการคำนวณ"】**: คลิกปุ่มสีน้ำเงิน "เริ่มจำลองการคำนวณ" บนการ์ดมุมซ้ายบน ปุ่มจะเปลี่ยนเป็น "กำลังจำลอง..." ขณะคำนวณความต่างในหน่วยความจำโดยไม่แตะต้องไฟล์บนดิสก์
- **【ขั้นตอนที่ 2: ตรวจสอบสัญลักษณ์ในตัวอย่าง】**: รายการจะขยายออกด้านล่าง: `+` สีเขียว (คัดลอกใหม่), `➔` สีน้ำเงิน (เปลี่ยนชื่ออัจฉริยะ), `−` สีแดง (ลบ ย้ายไปถังรีไซเคิลก่อน)
- **【ขั้นตอนที่ 3: คลิก "ยืนยันและซิงค์"】**: หลังตรวจรายการแล้ว คลิก "ยืนยันและซิงค์" ที่มุมขวาล่างเพื่อใช้การเปลี่ยนแปลงกับทุกดิสก์ การแจ้งเตือน Toast ด้านบนจะยืนยันเมื่อเสร็จสิ้น

### 2.3 ตัวควบคุม ตำแหน่ง และมาตรการป้องกัน

| ปุ่ม / ตัวควบคุม | ตำแหน่งบนหน้าจอ | หน้าที่และวัตถุประสงค์ | วิธีใช้ | ผลลัพธ์ที่คาดหวังและการป้องกัน |
| :--- | :--- | :--- | :--- | :--- |
| **เริ่มจำลองการคำนวณ** | มุมซ้ายบนของการ์ดหลัก (ปุ่มสีน้ำเงิน) | จำลองการตรวจสอบและเทียบข้อมูลระหว่างทุกปลายทาง | คลิกปุ่ม | เปลี่ยนเป็น "กำลังจำลอง..." แล้วแสดงรายการตัวอย่างการเปลี่ยนแปลงด้านล่าง |
| **ยืนยันและซิงค์** | มุมขวาล่างของรายการตัวอย่าง | เขียนการเปลี่ยนแปลงที่ตรวจแล้วลงดิสก์ปลายทาง | คลิกเพื่อยืนยัน | เริ่มเอนจินซิงค์ และ Toast ลอยด้านบนยืนยันว่าซิงค์สำเร็จ |

> **สัญลักษณ์ในตัวอย่าง**:
> - 🟢 **`+` (สีเขียว)**: ไฟล์ที่จะถูกเพิ่มหรือคัดลอก
> - 🔵 **`➔` (สีน้ำเงิน)**: ไฟล์ที่จะถูกเปลี่ยนชื่อในเครื่อง
> - 🔴 **`−` (สีแดง)**: ไฟล์ที่จะถูกลบ (**รับประกัน: ย้ายไปยังถังรีไซเคิลของ Windows ก่อน ไม่ลบถาวร**)

## บทที่ 3: โฟลเดอร์ (Folders)

### 3.1 วัตถุประสงค์และกลุ่มซิงค์หลายโฟลเดอร์
แท็บ **โฟลเดอร์** ใช้ตั้งค่าและจัดการเครือข่ายการซิงค์ของคุณด้วย **สถาปัตยกรรมกลุ่มโฟลเดอร์**:
- **ซิงค์หลายงานแบบแยกอิสระ**: สร้างกลุ่มซิงค์ที่แยกจากกันได้หลายกลุ่มพร้อมกัน (เช่น งาน รูปครอบครัว การเงินส่วนตัว)
- **ไปป์ไลน์และฉันทามติที่แยกอิสระ**: แต่ละกลุ่มมีโฟลเดอร์และที่เก็บฉันทามติ SQLite ของตัวเอง การซิงค์ขนาดใหญ่ในกลุ่มหนึ่งจะไม่ทำให้กลุ่มอื่นค้าง!

### 3.2 【คู่มือสำหรับผู้เริ่มต้น: ทำตามทีละขั้นตอน】
- **【ขั้นตอนที่ 1: สร้างและสลับกลุ่มซิงค์】**:
  1. คลิก "**+ กลุ่มใหม่**" ด้านบน ใส่ชื่อ เลือกไอคอน แล้วบันทึก
  2. คลิกชิปของกลุ่มเพื่อสลับกลุ่มที่ใช้งาน
  3. คลิก "**✎ แก้ไขกลุ่มซิงค์**" เพื่อเปลี่ยนชื่อหรือลบกลุ่ม (ไฟล์จริงบนดิสก์ยังอยู่ครบ)
- **【ขั้นตอนที่ 2: คลิก "เพิ่มโฟลเดอร์..."】**: คลิก "**เพิ่มโฟลเดอร์...**" ด้านล่างเพื่อเปิด File Explorer ของ Windows (แต่ละกลุ่มต้องมีอย่างน้อย 2 โฟลเดอร์)
- **【ขั้นตอนที่ 3: เลือกจาก 5 ตำแหน่งจัดเก็บ】**:
  1. **โฟลเดอร์ในเครื่องพีซี**: เปิด File Explorer ➔ คลิก "เอกสาร" หรือเข้าไปในไดรฟ์ `C:` ➔ เลือกโฟลเดอร์
  2. **OneDrive**: เปิด File Explorer ➔ คลิก "OneDrive" ที่แถบด้านข้าง ➔ เลือกโฟลเดอร์
  3. **Google Drive**: เปิด File Explorer ➔ คลิก "Google Drive" ➔ "ไดรฟ์ของฉัน" ➔ เลือกไดเรกทอรี
  4. **iCloud Drive (Windows)**: เปิด File Explorer ➔ คลิก "iCloud Drive" ที่แถบด้านข้าง ➔ เลือกไดเรกทอรี
  5. **แฟลชไดรฟ์ USB / ไดรฟ์พกพา**: เสียบไดรฟ์ USB ➔ เปิด File Explorer ➔ คลิกตัวอักษรไดรฟ์ (เช่น `D:` หรือ `E:`) ➔ เลือกโฟลเดอร์ (**แนะนำอย่างยิ่งให้ใช้รูปแบบ ExFAT**)
- **【ขั้นตอนที่ 4: เชื่อมโยงใหม่หรือลบออก】**: หากย้ายโฟลเดอร์ ให้คลิก "**เปลี่ยนโฟลเดอร์...**" คลิก "**ลบออก...**" เพื่อยกเลิกการผูก (การยกเลิกการผูกไม่ลบไฟล์จริง)

### 3.3 ตัวควบคุม ตำแหน่ง และมาตรการป้องกัน

| ตัวควบคุม / องค์ประกอบ | ตำแหน่งบนหน้าจอ | หน้าที่และวัตถุประสงค์ | วิธีใช้ | ผลลัพธ์ที่คาดหวังและการป้องกัน |
| :--- | :--- | :--- | :--- | :--- |
| **+ กลุ่มใหม่** | แถบกลุ่มซิงค์ด้านบน | สร้างกลุ่มซิงค์อิสระกลุ่มใหม่ | คลิกแล้วใส่ชื่อและไอคอน | ชิปกลุ่มใหม่ปรากฏขึ้นและสลับไปยังสถานะว่างโดยอัตโนมัติ |
| **✎ แก้ไขกลุ่มซิงค์** | ด้านขวาของข้อมูลกลุ่มที่ใช้งาน | เปลี่ยนชื่อ เปลี่ยนไอคอน หรือลบกลุ่ม | คลิกเพื่อเปิดแผ่นแก้ไข | รองรับการเปลี่ยนชื่อ การลบเป็นเพียงการยกเลิกการผูกและไม่แตะต้องไฟล์จริง |
| **เพิ่มโฟลเดอร์...** | ด้านล่างของรายการโฟลเดอร์ (ปุ่มสีน้ำเงิน) | เพิ่มไดเรกทอรีเข้าเครือข่ายซิงค์ | คลิกแล้วเลือกใน Explorer | เขียนไฟล์เครื่องหมาย UUID `.syncnexus-endpoint` ที่ไม่ซ้ำกัน |
| **เปลี่ยนโฟลเดอร์...** | ด้านขวาของการ์ดปลายทางแต่ละใบ | เชื่อมโยงใหม่เมื่อตัวอักษรไดรฟ์หรือพาธเปลี่ยน | คลิกแล้วเลือกพาธใหม่ | ตรวจสอบเครื่องหมายและกู้คืนการเชื่อมต่ออัตโนมัติ |
| **ลบออก...** | ด้านขวาของการ์ดปลายทางแต่ละใบ | ยกเลิกการผูกโฟลเดอร์ออกจากกลุ่มซิงค์ | คลิกแล้วยืนยันในกล่องโต้ตอบ | ยกเลิกการผูกจากการซิงค์ **ไม่ลบไฟล์จริง** |
| **การป้องกันด้วยเครื่องหมาย** | พื้นที่สถานะของการ์ดปลายทาง | ป้องกันการเสียบไดรฟ์ USB ผิดตัว | ตรวจสอบอัตโนมัติต่อเนื่อง | หากเสียบไดรฟ์ผิด จะแสดง "เครื่องหมายไม่ตรงกัน หยุดการแพร่กระจายแล้ว" และแยกออกโดยอัตโนมัติ! |

## บทที่ 4: ข้อขัดแย้ง (Conflicts)

### 4.1 วัตถุประสงค์
เมื่อมีการแก้ไขพร้อมกันแบบออฟไลน์บนสองอุปกรณ์ SyncNexus บังคับใช้ **นโยบายห้ามเขียนทับ** อย่างเคร่งครัด โดยบันทึกไฟล์ที่ขัดแย้งเป็น `ชื่อไฟล์ (conflict ...)` และรวบรวมไว้ที่นี่เพื่อเปรียบเทียบแบบเคียงข้างกันและจัดการ

### 4.2 【คู่มือสำหรับผู้เริ่มต้น: ทำตามทีละขั้นตอน】
- **【ขั้นตอนที่ 1: ดูป้ายข้อขัดแย้งสีแดง】**: เมื่อมีการแก้ไขพร้อมกันแบบออฟไลน์ ป้ายสีแดงจะปรากฏบนไอคอน "ข้อขัดแย้ง" ที่แถบด้านข้าง คลิกเพื่อเปิด
- **【ขั้นตอนที่ 2: ดูการ์ดสองคอลัมน์】**: การ์ดซ้ายแสดง "เวอร์ชันปัจจุบัน" การ์ดขวาแสดง "เวอร์ชันของปลายทาง" (มีป้าย "ใหม่กว่า" สีเขียว) พร้อมขนาด วันที่แก้ไข และที่มา
- **【ขั้นตอนที่ 3: แสดงใน File Explorer】**: คลิก "แสดงใน File Explorer" เพื่อเลือกไฟล์นั้นและเปรียบเทียบในโปรแกรมแก้ไขข้อความ
- **【ขั้นตอนที่ 4: เลือกวิธีแก้ไข】**:
  - คลิก "**เก็บเวอร์ชันนี้**" ทางซ้าย: เก็บไฟล์หลัก ส่งไปยังทุกปลายทาง และเก็บสำเนาข้อขัดแย้งเข้าคลัง
  - คลิก "**ใช้เวอร์ชันนี้**" ทางขวา: เลื่อนสำเนาข้อขัดแย้งให้เป็นไฟล์หลักอย่างเป็นทางการ และสำรองไฟล์หลักเดิมไว้ในเวอร์ชันเก่า

| ปุ่ม / ตัวควบคุม | ตำแหน่งบนหน้าจอ | หน้าที่และวัตถุประสงค์ | วิธีใช้ | ผลลัพธ์ที่คาดหวังและการป้องกัน |
| :--- | :--- | :--- | :--- | :--- |
| **เก็บเวอร์ชันนี้** | ด้านล่างของการ์ด "เวอร์ชันปัจจุบัน" ทางซ้าย | แก้ข้อขัดแย้งโดยเก็บไฟล์หลัก | คลิกปุ่ม | ไฟล์หลักยังเป็นฉบับทางการและแพร่ไปยังปลายทางอื่น สำเนาข้อขัดแย้งถูกเก็บเข้าคลังอย่างปลอดภัย |
| **ใช้เวอร์ชันนี้** | ด้านล่างของการ์ด "เวอร์ชันของปลายทาง" ทางขวา | แก้ข้อขัดแย้งโดยใช้สำเนาที่เข้ามา | คลิกปุ่ม | สำเนาข้อขัดแย้งกลายเป็นไฟล์ทางการ ไฟล์หลักเดิมถูกสำรองไว้ในเวอร์ชันเก่า |

## บทที่ 5: เวอร์ชันเก่า (Versions)

### 5.1 วัตถุประสงค์
ทุกครั้งที่ไฟล์ถูกเขียนทับหรือซิงค์ เวอร์ชันที่ถูกแทนที่จะถูกเก็บไว้ใน `.syncnexus-history` เพื่อให้ย้อนกลับได้ด้วยการคลิกเดียวทุกเมื่อ

### 5.2 【คู่มือสำหรับผู้เริ่มต้น: ทำตามทีละขั้นตอน】
- **【ขั้นตอนที่ 1: ตั้งนโยบายการเก็บรักษา】**: เลือกระยะเวลาเก็บ (7 / 30 / 90 วัน หรือถาวร) จากเมนูแบบเลื่อนลงด้านบน ไฟล์ที่หมดอายุจะถูกล้างอัตโนมัติในเบื้องหลัง
- **【ขั้นตอนที่ 2: ค้นหาเวอร์ชันที่ต้องการ】**: พิมพ์คำค้นของชื่อไฟล์ในช่องค้นหามุมขวาบน รายการเวอร์ชันจะถูกกรองทันที
- **【ขั้นตอนที่ 3: คลิก "กู้คืน" เพื่อนำไฟล์กลับมา】**: คลิก "**กู้คืน**" บนการ์ดเวอร์ชัน ไฟล์จะกลับเข้าไดเรกทอรีทำงานทันทีและซิงค์ไปยังทุกปลายทางภายใน 2 วินาที
- **【ขั้นตอนที่ 4: ดูแลพื้นที่จัดเก็บ (ไม่บังคับ)】**: คลิก "ล้างรายการหมดอายุเดี๋ยวนี้" เพื่อลบข้อมูลสำรองที่หมดอายุ หรือคลิก "ล้างทั้งหมด" เพื่อล้างคลังหลังยืนยัน (ไฟล์ที่ใช้งานอยู่จะไม่ได้รับผลกระทบ)

## บทที่ 6: การตรวจสอบ (Verification)

### 6.1 วัตถุประสงค์
SyncNexus ใช้ **อัลกอริทึมแฮชเข้ารหัส SHA-256** ตรวจสอบทุกไบต์ในทุกปลายทาง เพื่อป้องกันการถ่ายโอนที่ไม่สมบูรณ์และความเสียหายของดิสก์แบบเงียบ (bit-rot)

### 6.2 【คู่มือสำหรับผู้เริ่มต้น: ทำตามทีละขั้นตอน】
- **【ขั้นตอนที่ 1: เริ่มการตรวจสอบเชิงลึก】**: คลิกปุ่มสีน้ำเงิน "เริ่มตรวจสอบเดี๋ยวนี้" บนการ์ดตรงกลาง เอนจินจะคำนวณแฮช SHA-256 ของทุกปลายทางในเบื้องหลัง
- **【ขั้นตอนที่ 2: ดูรายงานการตรวจสอบ】**: เมื่อเสร็จจะอัปเดตเวลา "การตรวจสอบเชิงลึกล่าสุด" หากตรงกันทั้งหมดจะแสดงป้ายสีเขียว "ปกติทั้งหมด" หากพบความเสียหายจะแสดงรายการไฟล์ที่เสียหาย
- **【ขั้นตอนที่ 3: ซ่อมแซมไฟล์ที่เสียหาย】**:
  - คลิก "**ซ่อมแซมจากปลายทางอื่น**": ดาวน์โหลดสำเนาที่ถูกต้องระดับบิตจากปลายทางที่สมบูรณ์มาแทนไฟล์ที่เสียหาย (ไฟล์ที่เสียหายจะถูกสำรองเข้าประวัติก่อน)
  - คลิก "**ยอมรับเนื้อหาปัจจุบัน**": หากการเปลี่ยนแปลงเป็นความตั้งใจ จะคำนวณแฮชฐานใหม่และล้างการแจ้งเตือน

### 6.3 ตัวควบคุม ตำแหน่ง และมาตรการป้องกัน

| ปุ่ม / ตัวควบคุม | ตำแหน่งบนหน้าจอ | หน้าที่และวัตถุประสงค์ | วิธีใช้ | ผลลัพธ์ที่คาดหวังและการป้องกัน |
| :--- | :--- | :--- | :--- | :--- |
| **เริ่มตรวจสอบเดี๋ยวนี้** | ด้านขวาของการ์ดตรงกลาง (ปุ่มสีน้ำเงิน) | เริ่มคำนวณแฮช SHA-256 เชิงลึก | คลิก "**เริ่มตรวจสอบเดี๋ยวนี้**" | คำนวณเบื้องหลัง เมื่อเสร็จจะอัปเดตเวลาและรายการความผิดปกติ |
| **ซ่อมแซมจากปลายทางอื่น** | ปรากฏเมื่อพบไฟล์เสียหาย | ดาวน์โหลดไฟล์ที่ถูกต้องจากปลายทางที่สมบูรณ์ | คลิกเพื่อซ่อมแซม | ดาวน์โหลดสำเนาต้นฉบับจากปลายทางที่สมบูรณ์ ไฟล์เสียหายที่ถูกแทนที่จะถูกเก็บไว้ในประวัติ |
| **ยอมรับเนื้อหาปัจจุบัน** | ปรากฏเมื่อพบไฟล์เสียหาย | อัปเดตแฮชฐานหากการเปลี่ยนแปลงเป็นความตั้งใจ | คลิกเพื่อยอมรับ | คำนวณแฮชฐานใหม่ในที่เก็บฉันทามติและเอาป้ายเตือนออก |

## บทที่ 7: การตั้งค่า (Settings)

### 7.2 【คู่มือสำหรับผู้เริ่มต้น: ทำตามทีละขั้นตอน】
- **【ขั้นตอนที่ 1: เลือกนโยบายข้อขัดแย้ง】**: เลือก "เก็บทั้งสองเวอร์ชันแล้วให้ฉันเลือก (แนะนำ)" หรือ "เวอร์ชันใหม่กว่าชนะ เก็บเวอร์ชันเก่าไว้ในเวอร์ชันเก่า"

- **【ขั้นตอนที่ 3: ตั้งภาษาและการเริ่มต้นระบบ】**: เลือกจาก 6 ภาษา เปิด "เริ่มเมื่อเข้าสู่ระบบ" เพื่อให้แอปเริ่มทำงานเงียบ ๆ ในถาดระบบของ Windows
- **【ขั้นตอนที่ 4: ดูบันทึกและคู่มือ】**: คลิก "เปิดไฟล์บันทึก" เพื่อดูข้อมูลวินิจฉัยการซิงค์ใน Notepad คลิก "คู่มือเริ่มต้นใช้งาน" เพื่อทบทวนวิธีใช้สำหรับผู้เริ่มต้น

## สรุป: กฎเพื่อความอุ่นใจในทุกวัน

1. **ทำงานได้อย่างอิสระโดยไม่ต้องคลิกเอง**: ตราบใดที่โฟลเดอร์แสดง "ออนไลน์" การบันทึกหรือเปลี่ยนชื่อไฟล์จะซิงค์ไปยังทุกปลายทางภายใน 2 วินาที
2. **หากไม่แน่ใจ ให้จำลองก่อน**: ก่อนจัดระเบียบหรือลบไฟล์จำนวนมาก ไปที่ "ดูตัวอย่างความต่าง" แล้วคลิก "เริ่มจำลองการคำนวณ"
3. **ไม่ต้องตกใจเมื่อลบไฟล์**: ตรวจสอบถังรีไซเคิลของ Windows ก่อน หากล้างไปแล้ว ให้เปิด "เวอร์ชันเก่า" ค้นหาไฟล์ แล้วคลิก "กู้คืน" ข้อมูลของคุณปลอดภัยเสมอ!
