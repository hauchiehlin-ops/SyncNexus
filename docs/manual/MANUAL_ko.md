# Sync-Nexus 사용 설명서 (한국어)

## 1. 개요
**Sync-Nexus**는 macOS 및 Android를 위해 설계된 로컬 우선(Local-First) 양방향 파일 동기화 도구입니다. 엄격한 데이터 무결성 보장, 클라우드 종속성 제로, 완전 오프라인 아키텍처 및 텔레메트리 수집 없는 프라이버시 보호를 제공합니다.

---

## 2. 주요 기능
* **클라우드 제로 아키텍처**: 모든 파일 대조 및 동기화 작업은 사용자 기기 로컬 내에서 실행되거나 동일한 Wi-Fi 로컬 네트워크(mDNS / P2P)를 통해 직접 전송되며 외부 서버를 거치지 않습니다.
* **로컬 피어 탐색 (P2P)**: 동일한 Wi-Fi 환경에 있는 Mac과 Android 기기를 계정 로그인 없이 자동으로 감지하여 직접 연결을 구성합니다.
* **스마트 대조 및 차이 미리보기 (Visual Diff Trial Run)**: 실제 동기화를 적용하기 전에 변경될 항목(추가, 수정, 삭제)을 시험 실행(Trial Run)으로 사전 확인할 수 있습니다.
* **APFS 스냅샷 보호 (macOS)**: APFS 파일 시스템 환경에서 대규모 동기화 전 시스템 스냅샷을 자동 생성하여 안전한 복원 지점을 제공합니다.
* **배터리 및 전원 상태 감지 (Android)**: 배터리가 15% 미만이고 충전 중이 아닌 경우 전력 소모가 큰 백그라운드 동기화를 자동 연기하여 배터리를 보호합니다.
* **OTG USB 드라이브 즉시 감지 (Android)**: USB 드라이브 또는 외장 하드가 연결되는 즉시 인식하여 동기화 엔드포인트로 설정할 수 있습니다.
* **충돌 격리 및 무손실 보호**: 여러 기기에서 동시 수정이 발생한 경우 파일을 덮어쓰지 않고 양쪽 버전을 모두 보존합니다.

---

## 3. 시작하기

### macOS 버전
1. **Sync-Nexus.app**을 실행합니다.
2. **폴더 추가**를 클릭하여 동기화할 폴더를 2개 이상 선택합니다 (로컬 폴더, iCloud Drive, 외장 드라이브 등).
3. 시스템 표준 선택 창에서 보안 범위 북마크(Security-Scoped Bookmarks) 권한을 허용합니다.
4. 메뉴 막대 팝오버 또는 기본 창에서 실시간 동기화 상태를 확인합니다.
5. 대규모 파일 변경 전에는 **차이 미리보기** 탭에서 시험 실행을 통해 변경 사항을 검토할 수 있습니다.

### Android 버전
1. Android 스마트폰 또는 태블릿에서 **Sync-Nexus**를 실행합니다.
2. **폴더 추가…** 버튼을 눌러 저장소 접근 프레임워크(SAF)를 통해 폴더를 선택합니다.
3. 2개 이상의 동기화 폴더를 추가합니다 (내부 저장소 폴더, SD 카드, OTG 드라이브 등).
4. **지금 동기화**를 누르거나 백그라운드 자동 스케줄링에 맡깁니다.
5. **동일 Wi-Fi 주변 기기** 카드에서 로컬 네트워크 내 Mac과의 P2P 연결 상태를 확인합니다.

---

## 4. 충돌 해결
동일한 파일이 양쪽에서 동시에 수정된 경우:
* Sync-Nexus는 기존 파일을 자동으로 덮어쓰지 않습니다.
* 충돌 복사본(예: `파일.conflict-copy.txt`)이 생성되어 안전하게 보존됩니다.
* **충돌** 탭에서 두 버전의 차이를 검토하고 보관할 버전을 선택할 수 있습니다.

---

## 5. 보안 및 개인정보 보호
* 광고 없음, 사용자 추적 없음, 텔레메트리 데이터 수집 없음.
* 네트워크 통신은 동일 로컬 네트워크 내의 Bonjour/mDNS 기기 탐색에만 한정됩니다.
