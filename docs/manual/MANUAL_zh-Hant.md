# Sync-Nexus 操作使用手冊（繁體中文）

## 1. 簡介
**Sync-Nexus** 是一款專為 macOS 與 Android 設計的「本機優先 (Local-First)」雙向檔案同步工具。具備強大的資料完整性保護、零雲端綁定、無伺服器架構與完全零遙測隱私保護。

---

## 2. 核心功能特色
* **零雲端架構**：所有檔案比對、對帳與同步皆完全在設備本機執行，或透過同 Wi-Fi 區域網路 (mDNS / P2P) 直連，無需經過任何第三方伺服器。
* **區域網路設備發現 (P2P)**：自動搜尋同 Wi-Fi 下的 Mac 與 Android 設備，無須註冊登入即可建立點對點直連。
* **智慧對帳與差異預覽 (Visual Diff Trial Run)**：在正式執行同步前，可先執行試跑預覽即將異動的檔案（新增、修改、刪除）。
* **APFS 快照保護機制 (macOS)**：在支援 APFS 的磁碟上執行大規模同步前，自動建立系統快照，提供無損復原保障。
* **電量與充電智慧感知 (Android)**：當設備電量低於 15% 且未接通充電器時，自動暫緩高耗能同步，守護手機續航力。
* **OTG USB 隨身碟即時偵測 (Android)**：插上隨身碟或外接硬碟時立即感知並可加入同步端點。
* **衝突隔離與資料零丟失**：發生併發衝突時，自動保留雙方修改版本，絕不靜默覆蓋。

---

## 3. 快速上手指南

### macOS 版本
1. 啟動 **Sync-Nexus.app**。
2. 點擊 **加入資料夾** 挑選兩個或多個欲同步的目錄（本機目錄、iCloud Drive、外接隨身碟等）。
3. 透過系統標準選取視窗授權目錄存取權限（安全範圍書籤 Security-Scoped Bookmarks）。
4. 可隨時從頂部選單列選單或主視窗即時檢視同步狀態與紀錄。
5. 同步大量變更前，可在「差異預覽」分頁進行試跑檢閱。

### Android 版本
1. 在 Android 手機或平板上開啟 **Sync-Nexus**。
2. 點擊 **加入資料夾…** 透過系統儲存空間存取架構 (SAF) 選取資料夾。
3. 選取至少兩個同步端點（例如：內部儲存空間文件夾與 SD 卡 / 外接隨身碟）。
4. 點擊 **立即對帳同步** 或仰賴系統背景智慧排程自動同步。
5. 檢視「同 Wi-Fi 近端設備」卡片，確認與同網路內的 Mac 建立點對點連線。

---

## 4. 衝突處理機制
當同一個檔案在兩端同時被修改時：
* Sync-Nexus 絕不會靜默覆蓋任何資料。
* 系統會自動建立保留副本（例如：`文件.conflict-copy.txt`）。
* 您可以在「衝突」分頁中檢視詳細差異，並選擇保留哪一方版本。

---

## 5. 安全與隱私承諾
* 無廣告、無使用者追蹤、無數據遙測收集。
* 網路功能僅用於局域網路 Bonjour/mDNS 設備發現，檔案內容永不離開您的區域環境。
