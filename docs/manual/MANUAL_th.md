# คู่มือการใช้งาน Sync-Nexus (ภาษาไทย)

## 1. บทนำ
**Sync-Nexus** เป็นเครื่องมือซิงค์ไฟล์สองทางแบบ "Local-First" ที่ออกแบบมาสำหรับ macOS และ Android มีการรับประกันความสมบูรณ์ของข้อมูล ไม่พึ่งพาคลาวด์ ไม่ต้องใช้เซิร์ฟเวอร์ และเคารพความเป็นส่วนตัวโดยไม่มีการติดตามข้อมูลใดๆ ทั้งสิ้น

---

## 2. คุณสมบัติหลัก
* **สถาปัตยกรรมไร้คลาวด์ (Zero-Cloud)**: การตรวจสอบ เปรียบเทียบ และซิงค์ไฟล์ทั้งหมดทำงานบนเครื่องของท่านโดยตรง หรือเชื่อมต่อผ่านเครือข่าย Wi-Fi ท้องถิ่นเดียวกัน (mDNS / P2P) โดยไม่ผ่านเซิร์ฟเวอร์ภายนอก
* **ค้นหาอุปกรณ์ในเครือข่ายท้องถิ่น (P2P)**: ตรวจหาอุปกรณ์ Mac และ Android ในเครือข่าย Wi-Fi เดียวกันโดยอัตโนมัติโดยไม่ต้องลงทะเบียนบัญชี
* **การตรวจสอบและดูความแตกต่างล่วงหน้า (Visual Diff Trial Run)**: สามารถทดลองรันเพื่อดูตัวอย่างไฟล์ที่จะมีการเปลี่ยนแปลง (เพิ่ม แก้ไข ลบ) ก่อนเริ่มซิงค์จริง
* **ระบบป้องกันด้วย APFS Snapshot (macOS)**: สร้าง Snapshot ของระบบโดยอัตโนมัติก่อนดำเนินการซิงค์ขนาดใหญ่บนไดรฟ์ที่รองรับ APFS เพื่อความปลอดภัยสูงสุด
* **ระบบจัดการพลังงานอัจฉริยะ (Android)**: ชะลอการซิงค์ที่ใช้พลังงานสูงเมื่อแบตเตอรี่ต่ำกว่า 15% และไม่ได้เสียบสายชาร์จ เพื่อประหยัดพลังงาน
* **ตรวจจับแฟลชไดรฟ์ OTG USB ทันที (Android)**: รับรู้การเชื่อมต่อแฟลชไดรฟ์หรือฮาร์ดไดรฟ์ภายนอกได้ทันทีและสามารถเพิ่มเป็นโฟลเดอร์ซิงค์ได้
* **แยกไฟล์ขัดแย้ง ป้องกันข้อมูลสูญหาย**: เมื่อมีการแก้ไขไฟล์พร้อมกัน ระบบจะเก็บไฟล์ทั้งสองเวอร์ชันไว้โดยไม่เขียนทับข้อมูลเดิม

## 3. เริ่มต้นใช้งาน

### เวอร์ชัน macOS
1. เปิดแอปพลิเคชัน **Sync-Nexus.app**
2. คลิก **เพิ่มโฟลเดอร์** เพื่อเลือกโฟลเดอร์ตั้งแต่ 2 โฟลเดอร์ขึ้นไป (โฟลเดอร์ในเครื่อง, iCloud Drive, ไดรฟ์ภายนอก ฯลฯ)
3. อนุญาตสิทธิ์การเข้าถึงผ่านหน้าต่างมาตรฐานของระบบ (Security-Scoped Bookmarks)
4. ตรวจสอบสถานะการซิงค์แบบเรียลไทม์ได้จากเมนูบาร์หรือหน้าต่างหลัก
5. ก่อนซิงค์ไฟล์จำนวนมาก สามารถไปที่แท็บ **ดูตัวอย่างความแตกต่าง** เพื่อทดลองรันตรวจสอบได้

### เวอร์ชัน Android
1. เปิดแอปพลิเคชัน **Sync-Nexus** บนโทรศัพท์หรือแท็บเล็ต Android
2. แตะ **เพิ่มโฟลเดอร์…** เพื่อเลือกโฟลเดอร์ผ่าน Storage Access Framework (SAF)
3. เลือกอย่างน้อย 2 โฟลเดอร์ (เช่น โฟลเดอร์ในเครื่อง และการ์ด SD / แฟลชไดรฟ์ USB)
4. แตะ **ซิงค์ทันที** หรือปล่อยให้ระบบทำงานเบื้องหลังโดยอัตโนมัติ
5. ดูการ์ด **อุปกรณ์ใกล้เคียงในเครือข่ายเดียวกัน** เพื่อตรวจสอบการเชื่อมต่อกับ Mac

---

## 4. การจัดการเมื่อเกิดข้อขัดแย้งของไฟล์
เมื่อไฟล์เดียวกันถูกแก้ไขพร้อมกันในทั้งสองฝั่ง:
* Sync-Nexus จะไม่เขียนทับไฟล์ใดๆ โดยพลการ
* ระบบจะสร้างไฟล์สำเนาขึ้นมา (เช่น `เอกสาร.conflict-copy.txt`)
* ท่านสามารถตรวจสอบและเลือกรุ่นที่ต้องการเก็บไว้ได้ในแท็บ **ข้อขัดแย้ง**

---

## 5. ความปลอดภัยและความเป็นส่วนตัว
* ไม่มีโฆษณา ไม่มีการติดตามพฤติกรรมผู้ใช้ และไม่มีการส่งข้อมูลการใช้งานออกไปภายนอก
* การเชื่อมต่อเครือข่ายใช้เฉพาะ Bonjour/mDNS เพื่อค้นหาอุปกรณ์ในวงแลนเดียวกันเท่านั้น
