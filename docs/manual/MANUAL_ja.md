# Sync-Nexus 操作マニュアル（日本語）

## 1. はじめに
**Sync-Nexus** は、macOS および Android 向けに設計された「ローカルファースト (Local-First)」双方向ファイル同期ツールです。高いデータ完全性保護、クラウドアカウント不要のサーバーレス設計、完全なテレメトリゼロのプライバシー保護を提供します。

---

## 2. 主な機能
* **ゼロクラウド設計**：すべてのファイル検証・照合・同期処理はデバイスのローカル内、または同一 Wi-Fi ネットワーク (mDNS / P2P) 間でのみ実行され、外部サーバーを経由しません。
* **ローカルピア検出 (P2P)**：同一 Wi-Fi 内の Mac や Android デバイスを自動検出し、事前登録なしにダイレクト接続を確立します。
* **スマート照合と差分プレビュー (Visual Diff Trial Run)**：同期を実行する前に、変更されるファイル（追加、変更、削除）のプレビュー（テスト実行）が可能です。
* **APFS スナップショット保護 (macOS)**：対応する APFS ボリュームで同期を行う前に、システムの復元ポイントとなるスナップショットを自動作成します。
* **バッテリー＆充電感知 (Android)**：バッテリー残量が 15% 未満で未充電の場合、電力消費の大きい同期処理を自動的に保留し、端末のバッテリーを保護します。
* **OTG USB ドライブ即時検出 (Android)**：USB メモリや外付けストレージの接続を即座に感知し、同期フォルダとして登録できます。
* **競合の自動隔離とデータ消失防止**：複数端末での同時編集が発生した場合、双方のファイルを別名で保持し、一方的な上書きを防ぎます。

---

## 3. クイックスタートガイド

### macOS 版
1. **Sync-Nexus.app** を起動します。
2. **フォルダを追加** をクリックして、同期する 2 つ以上のディレクトリを選択します（ローカルフォルダ、iCloud Drive、外付けドライブなど）。
3. macOS の標準ダイアログ（セキュリティスコープブックマーク）でアクセス権限を許可します。
4. メニューバーまたはメイン画面からリアルタイムの同期状況を確認できます。
5. 「差分プレビュー」で事前に変更内容をシミュレーションできます。

### Android 版
1. スマートフォンまたはタブレットで **Sync-Nexus** を開きます。
2. **フォルダを追加…** をタップし、Storage Access Framework (SAF) 経由で対象フォルダを選択します。
3. 2 つ以上のフォルダ（端末内ストレージと SD カード / USB メモリなど）を登録します。
4. **今すぐ同期** をタップするか、バックグラウンドでの自動同期に任せます。
5. 「ローカル近隣デバイス」カードで、同じ Wi-Fi 内の Mac との接続を確認します。

---

## 4. 競合（コンフリクト）の解決
同一ファイルが複数の場所で同時に変更された場合：
* Sync-Nexus はファイルを上書きしません。
* 複製ファイル（例：`ファイル.conflict-copy.txt`）が自動生成されます。
* 「競合」タブから変更内容を確認し、どちらのバージョンを残すか選択できます。

---

## 5. セキュリティとプライバシー
* 広告なし、追跡なし、テレメトリ収集なし。
* 通信は同一ネットワーク内の Bonjour/mDNS デバイス検出のみに限定されます。
