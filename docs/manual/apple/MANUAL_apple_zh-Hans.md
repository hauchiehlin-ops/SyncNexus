# SyncNexus 操作使用手册 — Apple (macOS) 完整指南

> **适用平台**：macOS 14.0 (Sonoma) 及更新版本  
> **当前版本**：1.2.0（build 22）  
> **核心设计原则**：本机优先（Local-First）、零云端服务器绑定（Zero-Cloud）、绝对数据安全（Trash-First & History-Protected）

## 页首导航栏功能说明

在主窗口的最上方，配置了全局操作的页首导航栏：

```
[ 当前页面主题标题 ] ------------------------- [ 语系切换下拉选单 ▾ ] [ 📖 操作手册 ] [ 🛡️ 隐私政策 ]
```

1. **语系切换下拉式菜单**：
   - **实际位置**：页首右上角第一个控制元件。
   - **功能用途**：支持即时切换 6 种界面语系（繁体中文、简体中文、English、日本語、한국어、ภาษาไทย）。
   - **操作方式**：点击展开下拉菜单，选取目标语言，整个应用程序界面立即切换，无需重启。
2. **操作说明手册按钮（📖 图标）**：
   - **实际位置**：语系菜单右侧。
   - **功能用途**：直接以原生应用内浮动窗口展开本操作手册，免联网、不重定向至 GitHub 网页。
   - **操作方式**：点击开启，随时查阅各页面功能与操作指引；按 `Esc` 或“关闭”随时返回工作画面。
3. **隐私权政策按钮（🛡️ 图标）**：
   - **实际位置**：操作手册按钮右侧。
   - **功能用途**：查阅 SyncNexus 的零云端隐私安全规范与沙盒安全边界。

## 第一章：概览 (Overview)

![概览画面](../assets/01_overview.png)

### 1.1 页面功能定位与目的
“概览”是 SyncNexus 的**全局健康仪表板**。您无需深入检查个别文件，只要看一眼概览页，就能掌握整个同步系统的健康状态、监控文件总量、上次完整验证时间、历史版本容量与各端点连线状况。

### 1.2 【零基础新手教学：手把手操作程序】
- **【步骤 1：检视页首快捷工具】**：主窗口最上方右侧常驻“语系选单”、“操作手册 📖”与“隐私政策 🛡️”按钮，点击可随时切换 6 国语言或展开原生手册。
- **【步骤 2：确认全局健康灯号】**：看一眼左上方健康徽章：绿灯“全部正常”代表一切就绪；若转为黄灯“警告”，代表有端点离线、冲突或异常事件需要留意。
- **【步骤 3：应对大量删除拦截卡片】**：若单次删除超过 25 个文件或 25%，标题下方会自动弹出醒目的防护卡片并暂停同步；点击右侧“审核并确认”按钮，在审核清单中点选“确认放行”或“取消并恢复”。
- **【步骤 4：查看端点与同网 P2P】**：中央卡片列出目前同步群组的所有文件夹状态；若同 Wi-Fi 内有其他执行 SyncNexus 的设备，下方 P2P 区块会自动显示“在线”直连。

### 1.3 介面按钮位置、产出现象与安全防护机制

## 第二章：差异预览 (Diff Preview)

![差异预览画面](../assets/02_diff_preview.png)

### 2.1 页面功能定位与目的
在正式写入磁盘之前，“差异预览”提供**模拟对账试跑（Dry-Run）**功能。对于管理重要专案、大容量文件夹的使用者，能事前预知即将复制、更名或删除的项目，零风险确认安全无虞。

### 2.2 【零基础新手教学：手把手操作程序】
- **【步骤 1：点击执行试跑模拟】**：在顶部卡片左侧，点击蓝色“执行试跑模拟”按钮。按钮立即转为“模拟计算中...”，系统在背景深度比对各端点，不修改任何磁盘文件。
- **【步骤 2：建立 APFS 快照防线（选用）】**：在大规模同步前，可点击“APFS 快照安全防护”建立系统还原点；若因系统限制无法建立，顶部会跳出快显 Toast 提示说明系统已自动启用废纸篓与历史库双重防线。
- **【步骤 3：核对变更清单与符号】**：计算完成后下方展开变更清单：绿色 `+` 代表新增复制；蓝色 `➔` 代表智慧更名；红色 `−` 代表删除（标注优先移入废纸篓）。若无变动则显示绿色勾勾“所有端点完全一致”。
- **【步骤 4：点击确定执行同步】**：确认变更项目无误后，点击清单右下角“确定执行同步”按钮，系统将变更写入各端点，完成后顶部弹出 Toast 提示“同步作业已完成”。

### 2.3 介面按钮位置、产出现象与安全防护机制

| 按钮 / 元件名称 | 画面实际位置 | 用途与目的 | 操作方式 | 产出之现象与安全机制 |
| :--- | :--- | :--- | :--- | :--- |
| **执行试跑模拟** | 顶部主卡片左侧（蓝色主要按钮） | 在不更动任何磁盘实体文件的前提下，模拟比对所有端点差异 | 点击按钮，按钮转为“模拟计算中...” | 计算完成后于下方展开详细的预览清单，显示总变动笔数（如“共有 3 个项目即将同步”）。 |
| **确定执行同步** | 模拟清单右下方（审核无误后出现） | 将预览核对过的变更真正写入至所有目标端点 | 点击确认同步 | 系统立即启动多端点文件同步作业，顶部弹出同步成功快显提示。 |
| **APFS 快照安全防护** | “执行试跑模拟”按钮右侧 | 调用 macOS 系统级 APFS 快照，在大型变更前建立系统还原点 | 点击按钮触发建立 | 成功时弹出“已建立 APFS 安全快照”；若磁盘格式不支持或非管理员权限，顶部跳出快显 Toast 提示说明（如下图）。 |

![快显提示 Toast](../assets/02_diff_preview_toast.png)

> **预览符号说明**：
> - 🟢 **`+` (绿色图标)**：预计新增或自其他端点复制过来的文件。
> - 🔵 **`➔` (蓝色图标)**：预计在目标端点重新命名的文件（避免重复传输）。
> - 🔴 **`−` (红色图标)**：预计删除的文件（**安全保证：一律先移入 macOS 废纸篓，绝不硬删**）。

### 2.4 日常使用秘诀与避坑指南
- 在整理重要大专案或批次删除整理前，先至本页点击“执行试跑模拟”，核对清单确认安全后再同步，万无一失。

## 第三章：文件夹 (Folders)

![文件夹端点管理](../assets/03_folders_endpoints.png)

### 3.1 页面功能定位与多文件夹同步群组 (Sync Groups)
“文件夹”是设定同步目标的核心基地。SyncNexus 采用业界顶尖的**“同步群组（Folder Groups）”架构模型**：
- **支持多任务独立同步**：您可以同时建立多个独立的同步群组（例如：“工作项目”、“家庭相片”、“个人财务”）。
- **全管线与排程隔离**：每个群组拥有专属的 2~N 个端点文件夹、独立的 SQLite 状态数据库、独立的文件变更监听管线与文件锁（SyncLock）。群组 A 正在同步大文件时，群组 B 的小文件同步完全不受影响，绝不互相卡顿！

### 3.2 【零基础新手教学：手把手操作程序】
- **【步骤 1：建立与切换同步群组】**：
  1. 点击顶部同步群组列的“**＋ 新增群组**”，输入群组名称（如：工作项目、家庭相片）并选择代表图标后保存。
  2. 点击上方不同群组标签（Chips）即可随时切换，下方端点清单即刻显示该群组所属的文件夹。
  3. 点击“**✎ 编辑同步群组**”可重新命名或安全删除群组（实体文件完整保留于磁盘）。
- **【步骤 2：点击加入文件夹按钮】**：在页面底部点击蓝色“**加入文件夹...**”按钮，打开系统访达（Finder）选取对话框（每个群组至少需加入 2 个文件夹以建立同步网络）。
- **【步骤 3：依指引选取 4 大存储位置】**：
  1. **电脑本机文件夹**：打开 Finder ➔ 点击侧边栏“文稿”或个人专属目录 ➔ 选取目标文件夹。
  2. **iCloud 云盘 (iCloud Drive)**：打开 Finder ➔ 点击侧边栏“iCloud 云盘”➔ 选取目标文件夹。SyncNexus 自动处理云端占位符，确保文件在本地水合（Download）后安全同步。
  3. **Google 硬盘 (Google Drive)**：打开 Finder ➔ 点击侧边栏“Google Drive”➔ 进入“我的云端硬盘”➔ 选取目标文件夹。
  4. **外接随身碟 / 行动硬盘 (USB / Type-C)**：插上随身碟 ➔ 打开 Finder ➔ 侧边栏“位置”选取该随身碟 ➔ 选取目标文件夹（**强烈建议格式化为 ExFAT**）。
- **【步骤 4：更换或移除端点】**：路径搬移时点击端点卡片右侧“**更换文件夹...**”；若要解除同步点击“**移除...**”（仅解除关联，绝不删除实体文件）。

### 3.3 介面按钮位置、产出现象与安全防伪标记

| 按钮 / 元件名称 | 画面实际位置 | 用途与目的 | 操作方式 | 产出之现象与安全机制 |
| :--- | :--- | :--- | :--- | :--- |
| **＋ 新增群组** | 顶部同步群组列右侧 | 建立新的多向同步群组 | 点击并输入名称、选取图标 | 顶部新增群组标签，自动切换至新群组空白状态。 |

## 第四章：冲突 (Conflicts)

![冲突管理画面](../assets/04_conflicts.png)

### 4.1 页面功能定位与目的
当您在无网络或离线状态下，同时在两台电脑修改了同一个文件（例如 Mac 改了第 5 行、Windows 改了第 10 行），传统软件常会直接把其中一方盖掉造成悲剧。SyncNexus 坚持**“绝对不覆盖”原则**：将冲突版本妥善另存为 `文件名 (conflict ...)`, 并集中于本页让您自主比对与决定。

### 4.2 【零基础新手教学：手把手操作程序】
- **【步骤 1：察看侧栏冲突警示红标】**：当离线时两端同时编辑同个文件，侧边栏“冲突”图标会亮起红色数字徽章，点击进入冲突管理页面。
- **【步骤 2：左右并列对照两份版本】**：中央呈现双栏卡片：左栏为“目前主要版本”，右栏为“来自端点版本”（标注绿色“较新”标签），清楚列出文件大小、修改时间与来源端点。
- **【步骤 3：在访达中打开比对内容】**：若想详细比对内文，点击两侧卡片内的“在 Finder 中显示”按钮，系统自动在访达中标出该文件，方便以文本编辑器打开检查。
- **【步骤 4：点击仲裁按钮完成解决】**：
  - 点击左侧“**保留此版本**”：以主要版本为标准推播至各端点，冲突副本安全归档。
  - 点击右侧“**改用此版本**”：采用冲突副本取代主要文件，旧版本自动存入“旧版本库”备份。
  - 完成后侧栏红标归零，显示“没有未解决的冲突”。

### 4.3 介面按钮位置、产出现象与双版本仲裁

| 按钮 / 元件名称 | 画面实际位置 | 用途与目的 | 操作方式 | 产出之现象与安全机制 |
| :--- | :--- | :--- | :--- | :--- |
| **保留此版本** | 左侧“目前主要版本”卡片下方 | 决定采用主要版本内容作为标准版本 | 点击按钮 | 主要版本维持现状并推播至其他端点，冲突副本安全归档。 |
| **改用此版本** | 右侧“冲突副本版本”卡片下方（绿色标签“较新”） | 决定以冲突副本的内容覆盖并作为标准版本 | 点击按钮 | 冲突副本内容扶正为正式文件，旧的主要版本自动移至“旧版本库”备份。 |
| **在 Finder 中显示** | 两侧版本卡片内均有配置 | 在 macOS 访达中直接定位实体文件 | 点击按钮 | 系统自动打开 Finder 并反白选取该文件，方便您用文本编辑器比对。 |
| **无冲突状态** | 列表无任何冲突时呈现 | 确认系统内没有任何待决冲突 | 只读显示 | 呈现绿色勾勾图标“没有未解决的冲突，所有文件完全一致”。 |

### 4.4 日常使用秘诀与避坑指南
- 若内容互有取舍，可先点击“在 Finder 中显示”，将两份文件的修改手动合并至主档后，再点击“保留此版本”。

## 第五章：旧版本 (Versions)

![旧版本管理画面](../assets/05_versions.png)

### 5.1 页面功能定位与目的
“旧版本”是您的**历史时光机与防手残中心**。每当文件被修改覆盖、或是被同步覆写时，被取代的旧内容会完整保存于 `.syncnexus-history` 数据库中，让您随时可以一键找回昨天的草稿或被意外更动的内容。

### 5.2 【零基础新手教学：手把手操作程序】
- **【步骤 1：设定历史保留天数】**：在顶部卡片“历史保留期限”下拉菜单中，选取保留时间（7天 / 30天 / 90天 / 永久），系统会在背景自动清理逾期文件以释放空间。
- **【步骤 2：搜索目标历史文件】**：在右上角搜索输入框中，输入档名关键字或文件夹名称，历史清单即时过滤出匹配的修订版本。
- **【步骤 3：一键还原救回文件】**：在历史记录项目右侧，点击“还原”按钮；目标文件立即被该历史版本替换，顶部弹出成功 Toast 提示，且 2 秒内同步更新至所有其他端点。
- **【步骤 4：手动空间清理（选用）】**：若磁盘空间不足，点击“清理过期版本”立即释放逾期容量；点击“清空全部”则可在通过二次确认后清空历史库（绝不影响正在使用的正式文件）。

## 第六章：验证纪录 (Verification)

![验证纪录画面](../assets/06_verification.png)

### 6.1 页面功能定位与目的
现代硬盘可能发生无声数据损坏（Silent Bit-rot），网络传输也可能遇到封包不全。SyncNexus 采用工业级 **SHA-256 哈希技术**，对所有端点的所有文件进行逐 Byte 深度比对，确保每一处文件都真真切切百分之百一致。

### 6.2 【零基础新手教学：手把手操作程序】
- **【步骤 1：启动深层完整验证】**：在中央卡片右侧，点击蓝色“立即执行完整验证”按钮。系统在背景逐一计算所有端点文件的 SHA-256 哈希值。
- **【步骤 2：检视验证结果报告】**：验证完成后，顶部更新“最近完整验证”时间戳记。若所有文件一致，显示绿色徽章“全部正常，没有异常”；若发现损坏或位元错误，条列受影响的文件清单。
- **【步骤 3：修复受损文件】**：
  - 点击“**从其他端点修复**”：系统自动从健康的端点下载干净正确的副本覆盖修复，受损文件先备份进历史库后修复。
  - 点击“**接受目前内容**”：若变更为有意修改，点击重新计算基准哈希值并解除警报。
- **【步骤 4：了解四大内建防线】**：页面底部卡片详细列出：每次复制校验哈希、外接磁盘读回双重检查、覆写前存入旧版本、大量删除拦截。

### 6.3 介面按钮位置、产出现象与四大防线

| 按钮 / 元件名称 | 画面实际位置 | 用途与目的 | 操作方式 | 产出之现象与安全机制 |
| :--- | :--- | :--- | :--- | :--- |
| **立即执行完整验证** | 中央卡片右侧蓝色按钮 | 启动全端点深层 SHA-256 完整性哈希比对 | 点击“**立即验证**” | 背景扫描计算，验证完毕后更新“最近完整验证”时间与异常项目清单。 |
| **从其他端点修复** | 发现损坏异常项目时出现（主要按钮） | 从健康完好的其他端点下载正确文件覆盖受损文件 | 点击修复 | 自动从健康的端点提取干净副本覆写，受损文件先备份进历史库后修复。 |
| **接受目前内容** | 发现损坏异常项目时出现（次要按钮） | 确认目前文件内容为预期结果，重新计算哈希 | 点击接受 | 系统更新本机数据库的基准哈希，不再发出警示。 |
| **系统安全防线清单** | 页面底部卡片 | 呈现 SyncNexus 内建的四大防护架构 | 只读查阅 | 标注：先进废纸篓、防伪标记、大量删除拦截、SHA-256 全时监控。 |

### 6.4 日常使用秘诀与避坑指南
- 建议每个月点击一次“立即验证”，替所有备份硬盘做一次全面的健康检查。

## 第七章：设置 (Settings)

![设置画面](../assets/07_settings.png)

### 7.1 页面功能定位与目的
“设置”提供个性化的同步偏好微调，包含冲突处理策略、黑名单排除规则、多国语言以及 macOS 系统完全磁盘访问权限指引。

### 7.2 【零基础新手教学：手把手操作程序】
- **【步骤 1：挑选冲突处理原则】**：在第一张卡片中，单选“保留两份，由我挑选（推荐，默认）”可在冲突时生成副本并由您决定；“自动采用较新，旧的存进旧版本”则自动以最新修改时间为准。
- **【步骤 2：自订排除规则开关】**：在第二张卡片中，开启或关闭特定类型文件排除开关（如 `node_modules` 程序库、`.git` 版本库、数据库暂存文件 `-wal`/`-shm`、照片图库 `.photoslibrary`），被排除项目不会被同步传输。
- **【步骤 3：设定语系与开机启动】**：在第三张卡片中，使用下拉菜单切换 6 国语言（繁体中文、简体中文、English、日本語、한국어、ภาษาไทย）；切换开关设定“开机自动启动”，登录 Mac 时自动于菜单栏后台守护。
- **【步骤 4：检查完全磁盘访问权限】**：在权限卡片中，若显示黄灯“未授权”，点击“打开系统设置”按钮直达 macOS“隐私与安全性 ➔ 完全磁盘访问权限”，勾选 SyncNexus 即可获取完整读写权限；下方另有“打开日志文件”可调阅即时诊断记录。

## 总结：日常安心使用守则

1. **放松工作，免手动按键**：只要端点均呈现“在线”，在任一文件夹内保存或改名，2 秒内所有端点自动完成同步。
2. **有疑虑先“试跑模拟”**：在大批搬移或重整文件前，先到“差异预览”按一下“执行试跑模拟”，万无一失。
3. **误删文件免惊慌**：先翻 Mac“废纸篓”；若已被清理，直接进“旧版本”页面点击“还原”，数据永远都在！
