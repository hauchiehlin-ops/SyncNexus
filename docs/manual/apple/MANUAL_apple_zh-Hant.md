# SyncNexus 操作使用手冊 — Apple (macOS / iOS) 篇

## 1. 簡介與特色
**SyncNexus for Apple** 是一款為 Mac 與 iPhone 使用者量身打造的「本機優先」檔案即時自動同步工具。零雲端綁定、免伺服器，讓多處資料夾永遠保持一模一樣。

* **本機沙盒運行**：嚴格符合 Apple App Store 沙盒規範（App Sandbox），不擅自存取未經您授權的任何檔案。
* **同 Wi-Fi 區域網路直連**：支援 Apple Bonjour，在同一個 Wi-Fi 下能自動發現其他 Mac、Windows 電腦或 Android 手機。
* **防手殘與歷史版本**：檔案有任何取代或刪除，自動備份在歷史版本庫中；同時支援系統垃圾桶機制，隨時安心復原。
* **支援多種儲存端點**：Mac 本機資料夾、iCloud 雲碟、Google Drive 雲端硬碟、外接 USB 隨身碟與行動硬碟。

---

## 2. 快速上手：如何加入同步資料夾？

在主畫面「資料夾」分頁點擊「**加入資料夾...**」，選擇您想保持同步的目錄（至少加入 2 個）：

1. **電腦本機資料夾**：
   - 點開「Finder（訪達）」，點選左側側邊欄的「文件」或您的個人專屬資料夾，選取準備要同步的目錄。
2. **iCloud 雲碟 (iCloud Drive)**：
   - 點開「Finder（訪達）」，點擊左側側邊欄的「iCloud 雲碟」後，選取準備要同步的目錄。
3. **Google 雲端硬碟 (Google Drive)**：
   - 點開「Finder（訪達）」，點擊左側側邊欄的「Google Drive」、再點擊「我的雲端硬碟」後，選取準備要同步的目錄。
4. **外接式隨身碟 / 行動硬碟 (USB / Type-C)**：
   - 將外接磁碟插入 Mac 電腦，點開「Finder（訪達）」，在左側「位置」下方點擊您的外接磁碟名稱，選取準備要同步的目錄。磁碟格式建議格式化為 **ExFAT**，方便同時在 Mac 與 Windows 電腦之間共用！

## 3. 全自動同步與智慧防護

* **平時免手動操作**：
  只要您在其中任一個資料夾中新增、修改、改名或刪除檔案，SyncNexus 會在 2 秒內自動幫您同步到其他所有端點。
* **智慧差異預覽（試跑模擬）**：
  在正式同步前，您可以點擊「差異預覽」➔「執行試跑模擬」，系統會為您詳細列出預計會複製、改名或刪除的項目清單，零風險確認安全無虞。
* **兩邊同時修改（衝突保留）**：
  若在離線時兩邊修改了同一個檔案，SyncNexus 絕不覆蓋任何內容，會自動把另一份修改另存為衝突備份檔（例如 `檔案名稱 (conflict ...)`)，兩份檔案完整保留供您比對。
* **歷史版本與防誤刪（Versions）**：
  - 刪除的檔案優先移至系統「垃圾桶」，避免資料永久消失。
  - 被覆蓋的舊版本會妥善儲存在歷史庫中，切換到「舊版本」分頁即可一鍵還原。
  - 若單次刪除超過 25 個檔案或佔總檔案 25% 以上，系統會自動啟動「大量刪除防護」暫停同步，並跳出確認提醒，防止手殘誤刪。
