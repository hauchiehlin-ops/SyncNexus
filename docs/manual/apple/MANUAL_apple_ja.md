> **対応プラットフォーム**：macOS 14.0 (Sonoma) 以降  
> **現在のバージョン**：1.2.0（build 22）  
> **基本設計原則**：ローカルファースト（Local-First）、クラウド依存ゼロ（Zero-Cloud）、完全データ保護（Trash-First & History-Protected）

## ヘッダーナビゲーションバーの機能説明

メインウィンドウの最上部には、全体操作を司るヘッダーナビゲーションバーが配置されています：

```
[ 現在のページタイトル ] ------------------------- [ 言語切替プルダウン ▾ ] [ 📖 マニュアル ] [ 🛡️ プライバシー ]
```

1. **言語切替プルダウンメニュー**：
   - **配置場所**：ヘッダー右上。
   - **機能と目的**：6言語（繁体中国語、簡体中国語、英語、日本語、韓国語、タイ語）を即時切り替え。
   - **操作方法**：メニューを開いて言語を選択すると、再起動なしでアプリ全体の表示が即座に切り替わります。
2. **操作マニュアルボタン（📖 アイコン）**：
   - **配置場所**：言語メニューの右隣。
   - **機能と目的**：ブラウザを開くことなく、アプリ内ネイティブシートとして本マニュアルを表示。
   - **操作方法**：クリックして閲覧し、`Esc` キーまたは「閉じる」で作業画面に戻ります。
3. **プライバシーポリシーボタン（🛡️ アイコン）**：
   - **配置場所**：マニュアルボタンの右隣。
   - **機能と目的**：SyncNexus の完全ローカル同期・ゼロクラウド設計とデータ保護規約を確認。

## 第1章：概要 (Overview)

![概要画面](../assets/01_overview.png)

### 1.1 ページの位置付けと目的
「概要」は SyncNexus の**全体健全性ダッシュボード**です。個別のファイルを確認することなく、システム全体の同期状態、監視ファイル総数、最終検証日時、履歴容量、各フォルダの接続状態を一目で把握できます。

### 1.2 【入門チュートリアル：ステップ別操作手順】
- **【ステップ 1：ヘッダーバーの確認】**：画面右上には言語切り替え、「操作マニュアル 📖」、「プライバシー 🛡️」が常駐し、いつでも6言語の切り替えやマニュアル閲覧が可能です。
- **【ステップ 2：全体健全性ステータスの確認】**：左上の健全性バッジを確認：緑色の「すべて正常」なら順調、黄色の「警告」ならフォルダ切断や競合発生を示します。
- **【ステップ 3：大量削除保護カードへの対応】**：一度に25個または25%以上のファイルが削除された場合、上部に警告カードが表示され同期を一時停止します。右側の「確認して承認」を押し、削除を許可するか復元するかを選択します。
- **【ステップ 4：フォルダ一覧とローカル P2P の確認】**：中央に現在の同期グループのフォルダ一覧が表示され、同一 Wi-Fi 内の他デバイスは下部 P2P エリアに「オンライン」として自動検出されます。

### 1.3 操作ボタンの位置、動作現象と安全保護

| 項目名 | 画面上の位置 | 目的と機能 | 操作方法 | 動作現象と安全保護 |
| :--- | :--- | :--- | :--- | :--- |
| **全体健全性バッジ** | 左上タイトル横 | 全体の同期健全性を表示 | 常時自動監視 | 緑「すべて正常」；切断や競合時は黄色「警告」に切り替わり注意を促します。 |
| **大量削除保護カード** | タイトル直下（異常時のみ） | ランサムウェアや誤操作による一括消去を防ぐ | 右側の「**確認して承認**」をクリック | 25個または25%超の削除を自動停止。承認するまで削除は反映されません。 |
| **監視ファイル数タイル** | 指標エリア第1枠 | 監視対象ファイルの総数をリアルタイム表示 | 閲覧専用 | 「リアルタイム SHA-256 監視」と表示され、変更のたびに即時更新。 |
| **最終検証日時タイル** | 指標エリア第2枠 | 深層 SHA-256 完全性検証の実行日時 | 閲覧専用 | 「異常なし」または「破損の疑い X 件」と表示。 |
| **履歴容量タイル** | 指標エリア第3枠 | 過去バージョンが占有するディスク容量と保持期間 | 閲覧専用 | 例：「24.5 MB · 30日間保持、いつでも復元可能」。「履歴」タブで管理可能。 |
| **端点状態カード** | 中央グリッド | 各同期先フォルダの状態とファイルシステム属性 | カード情報確認 | 緑「オンライン」、黄「オフライン」、外付け時は「ExFAT / 取外し可能」を表示。 |
| **ローカル P2P 直結カード** | 下部ネットワーク部 | 同一 Wi-Fi 内の SyncNexus 稼働デバイスを自動探索 | 自動検出 | 見つかったデバイス名と緑の「オンライン」を表示し、P2P 直結同期を行います。 |

### 1.4 日常の使い方のヒント
- 上部に緑色の「すべて正常」が表示されていれば、すべてのフォルダが完全に同期されています。手動操作は一切不要で安心して作業できます。

## 第2章：差分プレビュー (Diff Preview)

![差分プレビュー画面](../assets/02_diff_preview.png)

### 2.1 ページの位置付けと目的
ディスクに変更を書き込む前に、差分プレビューで安全な**ドライランシミュレーション**が実行できます。各端点間のすべての差分を照合し、コピー、名前変更、削除の予定を確認できます。

### 2.2 【入門チュートリアル：ステップ別操作手順】
- **【ステップ 1：シミュレーション実行】**：上部カードの左側にある青い「シミュレーション実行」をクリック。「シミュレーション中...」となり、ディスクを一切変更せずに差分を計算します。
- **【ステップ 2：APFS スナップショット作成（任意）】**：大規模な変更前に「APFS スナップショット保護」で復元ポイントを作成可能。制限で作成できない場合も上部トーストでゴミ箱と履歴による安全保護を案内します。
- **【ステップ 3：差分リストの確認】**：計算完了後に変更一覧が表示されます：緑 `+` (新規/コピー)、青 `➔` (名前変更)、赤 `−` (ゴミ箱へ移動)。差分がなければ緑のチェックで「全フォルダ完全一致」と表示されます。
- **【ステップ 4：同期実行をクリック】**：一覧を確認後、右下の青い「同期を実行」ボタンをクリック。変更が全端点に書き込まれ、上部トーストで完了が通知されます。

### 2.3 操作ボタンの位置、動作現象と安全保護

| ボタン / 項目名 | 画面上の位置 | 目的と機能 | 操作方法 | 動作現象と安全保護 |
| :--- | :--- | :--- | :--- | :--- |
| **シミュレーション実行** | 上部カード左側（青ボタン） | ファイルを変更せずに全端点の差分をメモリ上で計算 | クリックして実行 | 「シミュレーション中...」となり、下部に予定件数（例：「3件の同期予定」）を展開。 |
| **同期を実行** | プレビュー一覧右下（確認後表示） | 確認した変更を全端点に書き込み | クリックして確定 | 同期処理が実行され、上部に成功トースト通知がポップアップします。 |
| **APFS スナップショット保護** | 「シミュレーション実行」の右隣 | macOS の APFS スナップショット復元ポイントを作成 | クリックして作成 | 成功時は「APFS スナップショット作成済み」、不可時は上部トーストで安全通知（下図）。 |

![トースト通知](../assets/02_diff_preview_toast.png)

> **プレビュー記号説明**：
> - 🟢 **`+` (緑)**：新規追加または他端点からコピーされるファイル。
> - 🔵 **`➔` (青)**：ローカルで名前変更されるファイル（再ダウンロードを回避）。
> - 🔴 **`−` (赤)**：削除予定ファイル（**安全保証：必ず macOS のゴミ箱に移動、完全消去は行いません**）。

### 2.4 日常の使い方のヒント
- 大きなプロジェクトの整理や一括削除の前には、まず「シミュレーション実行」をクリックして一覧を確認してから同期すると安心です。

## 第3章：フォルダ (Folders)

![フォルダ端点管理](../assets/03_folders_endpoints.png)

### 3.1 ページの位置付けと同期グループ (Sync Groups)
「フォルダ」は同期先を設定・管理する場所です。SyncNexus は業界をリードする**「同期グループ」アーキテクチャ**を採用しています：
- **複数タスクの独立管理**：複数のグループ（仕事、写真、個人データなど）を独立して保持できます。
- **排他制御とパイプラインの分離**：各グループが専用のフォルダ群、SQLite 状態 DB、監視パイプラインを独立保持。一方の大規模同期が他方に影響を与えることはありません。

### 3.2 【入門チュートリアル：ステップ別操作手順】
- **【ステップ 1：同期グループの作成と切り替え】**：
  1. 上部の「**＋ 新規グループ**」をクリックし、グループ名とアイコンを設定して作成。
  2. グループチップをクリックして表示するグループを切り替え。
  3. 「**✎ 同期グループを編集**」で名前の変更や安全な削除が可能です（ファイル実体は保護されます）。
- **【ステップ 2：フォルダの追加をクリック】**：下部の青い「**フォルダを追加...**」をクリックし、Finder でフォルダを選択します（各グループ最低2つ必要）。
- **【ステップ 3：4つの保存先の選択手順】**：
  1. **Mac ローカル**: Finder を開き、左サイドバーの「書類」または個人フォルダを選択。
  2. **iCloud Drive**: Finder を開き、サイドバーの「iCloud Drive」を選択。クラウド上のファイルも自動取得して同期します。
  3. **Google Drive**: Finder を開き、サイドバーの「Google Drive」➔「マイドライブ」を選択。
  4. **外付け USB ドライブ**: USB を接続し、Finder の「場所」からドライブを選択（**ExFAT 形式を強く推奨**）。
- **【ステップ 4：変更と解除】**：パス移動時は「**フォルダ変更...**」をクリック。除外時は「**削除...**」をクリック（実際のファイルは削除されません）。

### 3.3 操作ボタンの位置、動作現象とマーカー保護

| ボタン / 項目名 | 画面上の位置 | 目的と機能 | 操作方法 | 動作現象と安全保護 |
| :--- | :--- | :--- | :--- | :--- |
| **＋ 新規グループ** | グループバー右側 | 新しい同期グループを作成 | クリックして入力 | 新しいタブが追加され、空白状態で切り替わります。 |
| **✎ 同期グループを編集** | グループ情報カード右側 | グループ名の変更、アイコン変更、削除 | クリックして編集 | 削除時も同期設定が解除されるのみで、ディスク上のファイルは保持されます。 |
| **フォルダを追加...** | リスト下部の青ボタン | 同期対象フォルダを追加 | クリックして Finder で選択 | `.syncnexus-endpoint` UUID マーカーを自動生成し、セキュリティブックマークを作成。 |
| **フォルダ変更...** | 各カードの右側第1ボタン | パス移動時に再紐付け | クリックして新パス選択 | マーカー照合後に接続復帰。 |
| **削除...** | 各カードの右側第2ボタン | 同期設定から除外 | クリックして確認 | 監視リストから外れるだけで、**実際のファイルは一切削除されません**。 |
| **マーカー保護機能** | 端点カードのステータス部 | 異なる USB の挿入による誤上書きを防止 | 常時自動検証 | 別の USB が挿入された場合、「マーカー不一致、同期停止」（下図）として自動隔離保護！ |

![マーカー保護警告](../assets/03_folders_offline_marker.png)

### 3.4 日常の使い方のヒント
- 外付けドライブを ExFAT でフォーマットすると、ExFAT/Windows 互換ファイル名フィルターが自動有効化され、Mac と Windows 間で安全に同期できます。

## 第4章：競合 (Conflicts)

![競合管理画面](../assets/04_conflicts.png)

### 4.1 ページの位置付けと目的
オフライン時に同じファイルが両方で編集された場合、SyncNexus は**「上書きゼロ」原則**を守ります。競合バージョンを `ファイル名 (conflict ...)` として保持し、この画面で左右並べて比較・解決できます。

### 4.2 【入門チュートリアル：ステップ別操作手順】
- **【ステップ 1：赤い未解決バッジの確認】**：オフライン時に同じファイルが両方で編集されると、サイドバーの「競合」に赤い数字バッジが表示されます。クリックして画面を開きます。
- **【ステップ 2：左右並べてバージョン比較】**：左が「現在のバージョン」、右が「端点からのバージョン（緑の『新しい』バッジ付き）」として表示され、サイズ、更新日時、保存先を確認できます。
- **【ステップ 3：Finder で開いて内容照合】**：テキストの内容を細かく比較したい場合は、「Finder で表示」をクリックしてエディタで開いて確認できます。
- **【ステップ 4：解決ボタンをクリック】**：
  - 左の「**このバージョンを保持**」: プライマリを正式採用して全端点に同期し、競合コピーを安全に退避。
  - 右の「**このバージョンを採用**」: 競合コピーを正とし、以前のファイルは履歴庫に安全にバックアップ。
  - 解決するとバッジは消え、「未解決の競合はありません」と表示されます。

### 4.3 操作ボタンの位置、動作現象と安全保護

| ボタン / 項目名 | 画面上の位置 | 目的と機能 | 操作方法 | 動作現象と安全保護 |
| :--- | :--- | :--- | :--- | :--- |
| **このバージョンを保持** | 左カード下部 | プライマリを正として採用 | クリック | プライマリが維持され全端点に同期、競合ファイルは安全退避。 |
| **このバージョンを採用** | 右カード下部（緑バッジ付き） | 競合コピーを正として採用 | クリック | 競合ファイルが正式ファイルとなり、旧ファイルは「履歴」へ自動退避。 |
| **Finder で表示** | 各カード内 | Finder で対象ファイルを開く | クリック | Finder でファイルがハイライト表示され、エディタで比較可能。 |
| **未解決ゼロ状態** | 競合がない時の画面 | 競合がないことを確認 | 閲覧専用 | 緑のチェックマークで「未解決の競合はありません」を表示。 |

### 4.4 日常の使い方のヒント
- 両方の変更を残したい場合は、まず「Finder で表示」をクリックしてエディタで内容をマージしてから、「このバージョンを保持」をクリックしてください。

## 第5章：履歴 (Versions)

![履歴管理画面](../assets/05_versions.png)

### 5.1 ページの位置付けと目的
「履歴」はあなたの**タイムマシン**です。ファイルが更新または同期で上書きされるたびに、古い内容が `.syncnexus-history` に保存されます。誤って上書きしてしまっても、いつでもワンクリックで復元可能です。

### 5.2 【入門チュートリアル：ステップ別操作手順】
- **【ステップ 1：保持期間の設定】**：上部の「保持期間」プルダウンから（7日 / 30日 / 90日 / 無期限）を選択。期限切れファイルは自動削除され空き容量を保ちます。
- **【ステップ 2：過去ファイルの検索】**：右上の検索ボックスにファイル名やフォルダ名を入力すると、該当する履歴バージョンが即座に絞り込まれます。
- **【ステップ 3：復元ボタンで一発救出】**：履歴項目の右側にある「**復元**」ボタンをクリック。対象ファイルが過去バージョンで置き換わり、上部トーストで通知され、2秒以内に全端点に同期されます。
- **【ステップ 4：容量の手動整理（任意）】**：容量を空けたい時は「**期限切れをクリーンアップ**」をクリック。また「**すべてクリア**」で確認後に履歴全体を削除できます（作業中のファイルには一切影響しません）。

### 5.3 操作ボタンの位置、動作現象と安全保護

| ボタン / 項目名 | 画面上の位置 | 目的と機能 | 操作方法 | 動作現象と安全保護 |
| :--- | :--- | :--- | :--- | :--- |
| **保持期間プルダウン** | 上部「自動整理」右側 | 履歴の最大保存日数を設定 | 7日/30日/90日/無期限から選択 | 期限切れファイルはバックグラウンドで自動削除されます。 |
| **期限切れをクリーンアップ** | 保持期間の右隣 | 期限切れの過去ファイルを即座に削除 | クリック | 期限切れの履歴が削除され、容量表示が更新されます。 |
| **すべてクリア** | クリーンアップの右隣 | 履歴アーカイブ全体を空にする | クリックして確認 | 履歴庫のみを消去し、**作業中の実体ファイルには一切影響しません**。 |
| **検索ボックス** | リスト右上 | ファイル名や端点で絞り込み | キーワード入力 | 該当するファイルのみ即時絞り込み表示。 |
| **Finder で表示** | 検索ボックス右隣 | `.syncnexus-history` を Finder で開く | クリック | 履歴の保存先フォルダを直接開きます。 |
| **復元 (Restore)** | 各履歴項目の右側 | 選択した版を作業フォルダへ復元 | 「**復元**」をクリック | 作業ファイルが上書き復元され、2秒以内に全端点に同期されます。 |

### 5.4 日常の使い方のヒント
- 誤ってファイルを上書き・削除してしまった場合は、履歴画面でファイル名を検索して「復元」をクリックするだけで元通りになります！

## 第6章：検証記録 (Verification)

![検証記録画面](../assets/06_verification.png)

### 6.1 ページの位置付けと目的
サイレントビットロットやネットワーク転送エラーを防ぐため、工業規格の **SHA-256 ハッシュ**を用いてすべての端点のファイルを1バイトずつ検証し、完全性を保証します。

### 6.2 【入門チュートリアル：ステップ別操作手順】
- **【ステップ 1：完全検証の開始】**：中央カード右側の青い「**今すぐ完全検証を実行**」をクリック。全端点のすべてのファイルに対してバックグラウンドで SHA-256 ハッシュを計算します。
- **【ステップ 2：検証結果の確認】**：完了すると最終検証日時が更新されます。すべて一致していれば緑色の「異常なし」が表示され、破損やビット反転があれば問題ファイルが一覧表示されます。
- **【ステップ 3：破損ファイルの修復】**：
  - 「**他の端点から修復**」をクリック: 正常な端点から完全なファイルを自動ダウンロードして上書き修復（破損ファイルは事前に履歴庫に保存）。
  - 「**現在の内容を受け入れる**」をクリック: 意図した変更であれば、現在の内容を新たな基準ハッシュとして承認。
- **【ステップ 4：4大安全防線の確認】**：下部カードで、コピー時ハッシュ照合、外付け再読込確認、履歴保存、大量削除停止の防線を確認できます。

### 6.3 操作ボタンの位置、動作現象と安全保護

| ボタン / 項目名 | 画面上の位置 | 目的と機能 | 操作方法 | 動作現象と安全保護 |
| :--- | :--- | :--- | :--- | :--- |
| **今すぐ完全検証を実行** | 中央カード右側の青ボタン | 全端点の SHA-256 検証を開始 | クリックして開始 | バックグラウンドで計算し、完了後に日時と異常一覧を更新。 |

### 6.4 日常の使い方のヒント

## 第7章：設定 (Settings)

![設定画面](../assets/07_settings.png)

### 7.1 ページの位置付けと目的
「設定」では、競合ポリシーの調整、不要な一時ファイルの除外ルール設定、macOS のフルディスクアクセス権限、ログイン時自動起動を設定できます。

### 7.2 【入門チュートリアル：ステップ別操作手順】
- **【ステップ 1：競合ポリシーの選択】**：第1カードで「両方保持して手動選択 (推奨)」または「新しい方を自動採用」を選択します。
- **【ステップ 2：除外ルールの設定】**：第2カードで `node_modules`、`.git`、データベース一時ファイル (`-wal`, `-shm`)、写真ライブラリ (`.photoslibrary`) のスイッチを切り替え。除外された項目は転送されません。
- **【ステップ 3：言語と自動起動の設定】**：第3カードで6言語から好みの言語を選択。「ログイン時に起動」をオンにすると Mac 起動時にメニューバーで待機します。
- **【ステップ 4：フルディスクアクセスの確認】**：権限カードで「未認可」の場合、「**システム設定を開く**」をクリックして macOS の「プライバシーとセキュリティ ➔ フルディスクアクセス」で SyncNexus をオンにしてください。「**ログファイルを開く**」で詳細ログも確認できます。

### 7.3 操作ボタンの位置、動作現象と安全保護

| 設定項目 | 画面上の位置 | 目的と機能 | 操作方法 | 動作現象と安全保護 |
| :--- | :--- | :--- | :--- | :--- |
| **競合処理ポリシー** | 最初のカード | 同時編集発生時の初期動作を設定 | ラジオ選択：<br>1. **両方保持して手動選択** (推奨)<br>2. **新しい方を自動採用** | 選択1は競合コピーを作成して「競合」画面へ；選択2は更新日時で自動解決。 |
| **除外ルールスイッチ** | 2番目のカード | 同期不要なファイルやロックファイルを除外 | スイッチ切り替え：<br>• `node_modules`<br>• `.git`<br>• DB一時ファイル (`-wal`, `-shm`)<br>• 写真 (`.photoslibrary`) | 有効にすると該当項目は転送対象から除外され、帯域とディスク負荷を大幅に削減。 |

## まとめ：毎日の安心操作ルール

1. **手動操作なしで快適作業**：フォルダが「オンライン」になっていれば、ファイルを保存・変更するだけで2秒以内に自動同期。
2. **迷ったらまず「シミュレーション」**：大きな移動や削除の前は、「差分プレビュー」で「シミュレーション実行」を押して事前確認。
3. **誤って削除しても慌てない**：まずはゴミ箱を確認。空にしてしまった場合も「履歴」画面で「復元」を押せばデータは守られます！
