# Sync-Nexus 操作使用手册（简体中文）

## 1. 简介
**Sync-Nexus** 是一款专为 macOS 与 Android 设计的“本地优先 (Local-First)”双向文件同步工具。具备强大的数据完整性保护、零云端绑定、无服务器架构与完全零遥测隐私保护。

---

## 2. 核心功能特色
* **零云端架构**：所有文件比对、对账与同步均完全在设备本地执行，或通过同 Wi-Fi 局域网 (mDNS / P2P) 直连，无需经过任何第三方服务器。
* **局域网设备发现 (P2P)**：自动搜寻同 Wi-Fi 下的 Mac 与 Android 设备，无需注册登录即可建立点对点直连。
* **智能对账与差异预览 (Visual Diff Trial Run)**：在正式执行同步前，可先执行试跑预览即将变动的文件（新增、修改、删除）。
* **APFS 快照保护机制 (macOS)**：在支持 APFS 的磁盘上执行大规模同步前，自动建立系统快照，提供无损恢复保障。
* **电量与充电智能感知 (Android)**：当设备电量低于 15% 且未接通充电器时，自动暂缓高耗能同步，守护手机续航力。
* **OTG USB 闪存盘即时侦测 (Android)**：插入闪存盘或移动硬盘时即刻感知并可加入同步端点。
* **冲突隔离与数据零丢失**：发生并发冲突时，自动保留双方修改版本，绝不静默覆盖。

---

## 3. 快速上手指南

### macOS 版本
1. 启动 **Sync-Nexus.app**。
2. 点击 **添加文件夹** 挑选两个或多个欲同步的目录（本地目录、iCloud Drive、外接移动硬盘等）。
3. 通过系统标准选取窗口授权目录访问权限（安全作用域书签 Security-Scoped Bookmarks）。
4. 可随时从顶部菜单栏菜单或主窗口即时检视同步状态与记录。
5. 同步大量变更前，可在“差异预览”选项卡中进行试跑检阅。

### Android 版本
1. 在 Android 手机或平板上打开 **Sync-Nexus**。
2. 点击 **添加文件夹…** 通过系统存储访问框架 (SAF) 选取文件夹。
3. 选取至少两个同步端点（例如：内部存储空间文件夹与 SD 卡 / 移动闪存盘）。
4. 点击 **立即对账同步** 或依靠系统后台智能调度自动同步。
5. 检视“同 Wi-Fi 近端设备”卡片，确认与同网络内的 Mac 建立点对点连接。

---

## 4. 冲突处理机制
当同一个文件在两端同时被修改时：
* Sync-Nexus 绝不会静默覆盖任何数据。
* 系统会自动创建保留副本（例如：`文件.conflict-copy.txt`）。
* 您可以在“冲突”选项卡中检视详细差异，并选择保留哪一方版本。

---

## 5. 安全与隐私承诺
* 无广告、无用户追踪、无数据遥测收集。
* 网络功能仅用于局域网 Bonjour/mDNS 设备发现，文件内容永不离开您的局域环境。
