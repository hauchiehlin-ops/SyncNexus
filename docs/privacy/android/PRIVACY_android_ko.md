# SyncNexus 개인정보 처리방침 — Android (Google Play 심사 기준)

**시행일**: 2026년 10월 5일  
**배포 플랫폼**: Google Play 스토어 (Android)  
**개발자**: SyncNexus Team  

SyncNexus는 최고 수준의 개인정보 보호와 투명성을 준수합니다. 본 방침은 **Google Play 개발자 정책(사용자 데이터 정책 및 눈에 띄는 공개(Prominent Disclosure) 요건 포함)** 을 엄격히 따르며, 파일 접근과 시스템 권한을 어떻게 다루는지 설명합니다.

---

### 1. 핵심 약속: 서버 없음, 텔레메트리 없음
* **원격 서버 없음**: SyncNexus에는 백엔드 서버가 없습니다. 파일 내용, 경로 정보, SHA-256 해시는 모두 사용자의 기기와 사용자가 직접 선택한 저장소에서만 처리됩니다.
* **서드파티 SDK 및 광고 없음**: 추적, 분석, 광고, 비정상 종료 수집을 위한 서드파티 라이브러리를 포함하지 않습니다.
* **개인 식별 정보(PII) 없음**: 로그인이나 계정이 필요 없으며, 하드웨어 식별자(IMEI, Android ID 등)를 수집하거나 전송하지 않습니다.

---

### 2. 앱이 기기에 저장하는 데이터
차이 미리보기, 충돌, 이전 버전, 검증 기록 기능을 제공하기 위해 SyncNexus는 **앱 전용 저장소**에 다음을 보관합니다:
* 동기화 그룹마다, 모든 폴더가 일치했던 마지막 시점의 각 파일 해시와 수정 시각(어느 쪽이 변경되었는지 판단하는 데 사용).
* 해결되지 않은 충돌 목록.
* **버전 보관함**: 동기화 업데이트, 충돌 결정, 복원으로 교체된 파일의 사본. 30일간 보관하며(총 1 GB까지, 초과 시 오래된 것부터 삭제).
* 검증 기록(시각, 파일 수, 결과).

이 데이터는 **기기에만 저장되며 업로드되지 않습니다**. 그룹을 삭제하면 해당 기록도 삭제되고, 앱을 삭제하거나 Android 설정에서 데이터를 지우면 모두 삭제됩니다. 충돌 사본은 충돌이 발생한 동기화 폴더 안에 저장되며, 보관할지 버릴지는 사용자가 결정합니다.

---

### 3. Android 권한 및 눈에 띄는 공개 (Prominent Disclosure)
안정적인 로컬 파일 동기화를 위해 SyncNexus는 범위가 제한된 다음 권한을 사용합니다:
1. **저장소 접근 프레임워크 (SAF)**:
   - SyncNexus는 광범위한 `MANAGE_EXTERNAL_STORAGE` 권한을 요청하지 않습니다. 사용자가 시스템 문서 트리 선택기(`takePersistableUriPermission`)를 통해 특정 폴더에 대한 접근을 직접 허용합니다.
2. **포그라운드 서비스 (`FOREGROUND_SERVICE_DATA_SYNC`) 및 알림 (`POST_NOTIFICATIONS`)**:
   - 백그라운드 동기화를 안정적으로 실행하기 위해 Android가 요구합니다. 상시 알림에 각 동기화 그룹의 상태가 표시되어 동작이 항상 보입니다.
3. **네트워크 권한 (`INTERNET`, `ACCESS_WIFI_STATE`, `CHANGE_WIFI_MULTICAST_STATE`) 및 로컬 네트워크 서비스 검색 (NSD / mDNS)**:
   - NSD를 사용하려면 Android가 이 권한들을 요구합니다. **로컬 Wi-Fi 네트워크 안에서 주변의 SyncNexus 기기(Mac / Windows)를 찾는 용도로만** 사용합니다. 앱은 외부 서버에 연결하지 않으며 데이터를 업로드하거나 다운로드하지 않습니다.
4. **USB 기기 연결 리스너**:
   - 외부 USB OTG 드라이브의 연결·분리를 감지하여 동기화 엔드포인트 상태를 즉시 파악하는 용도로만 사용합니다.

---

### 4. 사용자 통제
사용자는 언제든지 앱에서 허용한 폴더를 삭제하거나 보관된 버전을 지울 수 있고, Android 시스템 설정에서 권한을 철회하거나 로컬 데이터를 삭제할 수 있습니다.
