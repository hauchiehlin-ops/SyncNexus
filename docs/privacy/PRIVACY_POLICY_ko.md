# 개인정보 처리방침 (한국어)

**시행일자**: 2026년 10월 2일  
**애플리케이션**: Sync-Nexus

Sync-Nexus는 로컬 우선(Local-First) 파일 동기화 도구입니다. 당사는 사용자의 개인정보를 엄격히 보호합니다. 본 방침은 본 애플리케이션의 데이터 처리 원칙을 설명합니다.

---

### 1. 데이터 수집 및 이용
* **서버리스 및 계정 불필요**: Sync-Nexus는 로컬 기기 및 로컬 네트워크 내에서만 작동하는 독립 실행형 도구입니다. 중앙 서버를 운영하지 않으며 계정 등록이 필요하지 않습니다.
* **텔레메트리 및 추적 없음**: 본 애플리케이션에는 외부 분석(Analytics)이나 사용자 행동 추적 SDK가 일절 포함되어 있지 않습니다.
* **외부 파일 유출 제로**: 동기화는 사용자가 지정한 로컬 폴더, 외장 저장 장치 또는 신뢰할 수 있는 로컬 Wi-Fi 네트워크 내의 기기 사이에서만 수행됩니다. 파일 내용, 파일 이름 및 메타데이터는 외부 서버로 절대 전송되지 않습니다.

---

### 2. 시스템 권한 안내
핵심 동기화 기능을 위해 다음과 같은 권한을 요청합니다:
* **사용자 선택 폴더 접근 권한 (User-Selected Files & Folders)**: 사용자가 앱 내에서 직접 선택한 폴더를 읽고, 감시하고, 동기화하는 데에만 사용됩니다.
* **보안 범위 북마크 (Security-Scoped Bookmarks / SAF)**: 샌드박스 환경에서 앱 재실행 후에도 허가된 폴더 접근 권한을 유지하기 위해 사용됩니다.
* **이동식 드라이브 접근 (Removable Volumes / OTG USB)**: 연결된 USB 드라이브 및 SD 카드를 감지하고 동기화하기 위해 사용됩니다.
* **로컬 네트워크 (Bonjour / mDNS)**: 동일한 Wi-Fi 내의 다른 기기를 검색하여 P2P 연결을 생성하는 데 사용되며, 인터넷을 통한 외부 전송은 발생하지 않습니다.
