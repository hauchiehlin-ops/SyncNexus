# นโยบายความเป็นส่วนตัวของ SyncNexus — Windows (ตามมาตรฐานการตรวจสอบของ Microsoft Store)

**วันที่มีผลบังคับใช้**: 3 ตุลาคม 2026  
**แพลตฟอร์ม**: Microsoft Store / การเผยแพร่บนเดสก์ท็อป Windows  
**ผู้พัฒนา**: SyncNexus Team  

SyncNexus มุ่งมั่นอย่างเต็มที่ในเรื่องความเป็นส่วนตัวและความโปร่งใสของผู้ใช้ นโยบายความเป็นส่วนตัวนี้สอดคล้องอย่างเคร่งครัดกับ **นโยบายการรับรองแอปของ Microsoft Store (โดยเฉพาะข้อ 10.5 ข้อมูลส่วนบุคคล)** โดยอธิบายสถาปัตยกรรมที่ประมวลผลข้อมูลในเครื่องเท่านั้นและไม่มีการเก็บข้อมูลการใช้งาน

---

### 1. คำประกาศเกี่ยวกับข้อมูลส่วนบุคคล
* **ไม่เก็บข้อมูลใด ๆ**: SyncNexus **ไม่เก็บ ส่ง จัดเก็บ หรือแบ่งปัน** ข้อมูลส่วนบุคคล ตัวระบุอุปกรณ์ หรือข้อมูลการใช้งานใด ๆ
* **ไม่มีเซิร์ฟเวอร์ระยะไกล**: การซิงค์เกิดขึ้นระหว่างระบบไฟล์ในเครื่องของคุณ ระบบไฟล์คลาวด์ที่เมานต์ในเครื่อง (Google Drive / OneDrive) และอุปกรณ์จัดเก็บข้อมูลแบบถอดได้เท่านั้น เนื้อหาไฟล์จะไม่ออกนอกอุปกรณ์ของคุณ
* **ไม่มีการวิเคราะห์จากบุคคลที่สาม**: ไม่มี SDK ของบุคคลที่สามสำหรับติดตาม โฆษณา วิเคราะห์ หรือเฝ้าดูพฤติกรรม

---

### 2. ความสามารถของ Windows และความโปร่งใส
1. **การเข้าถึงระบบไฟล์**:
   - ใช้เพื่ออ่าน เปรียบเทียบ และซิงค์โฟลเดอร์ที่ผู้ใช้เลือกอย่างชัดเจนเท่านั้น
2. **การใช้งาน Windows Cloud Files API**:
   - ใช้เพียงเพื่อตรวจสอบแอตทริบิวต์ตัวแทน `FILE_ATTRIBUTE_RECALL_ON_DATA_ACCESS` ในโฟลเดอร์ของ Google Drive และ OneDrive เพื่อป้องกันไม่ให้ไฟล์ที่ยังไม่ได้แคชถูกดาวน์โหลด (hydration) โดยไม่ตั้งใจ
3. **การค้นหาอุปกรณ์ในเครือข่ายภายใน (mDNS Multicast)**:
   - ส่งและรับ `_syncnexus._tcp.local` ภายใน Wi-Fi ของคุณผ่าน IP มัลติคาสต์ `224.0.0.251:5353` **ไม่มีการเชื่อมต่อกับเซิร์ฟเวอร์อินเทอร์เน็ตภายนอก**
4. **การตั้งค่าเริ่มต้นระบบ (Windows Startup Registry)**:
   - เมื่อผู้ใช้เปิดใช้งาน จะลงทะเบียนรายการใน `HKCU\Software\Microsoft\Windows\CurrentVersion\Run` เพื่อเริ่มโปรแกรมเฝ้าดูการซิงค์เบื้องหลังอย่างเงียบ ๆ สามารถปิดได้ทุกเมื่อผ่านการตั้งค่าหรือ Task Manager ของ Windows

---

### 3. ถังรีไซเคิลและความปลอดภัยของข้อมูล
* ไฟล์ที่ถูกลบจะถูกย้ายไปยัง **ถังรีไซเคิลของ Windows จริง** อย่างปลอดภัยด้วย Win32 `SHFileOperationW`
* การเก็บเข้าคลังใน `.syncnexus-history` ก่อนลบ ช่วยป้องกันข้อมูลหลายชั้น
