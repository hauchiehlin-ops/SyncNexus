# SyncNexus プライバシーポリシー — Windows (Microsoft Store 審査基準)

**施行日**：2026 年 10 月 3 日  
**配信プラットフォーム**：Microsoft Store / Windows デスクトップ配布  
**開発者**：SyncNexus Team  

SyncNexus は、ユーザーのプライバシーと透明性に全力で取り組んでいます。本プライバシーポリシーは **Microsoft Store アプリ認定ポリシー（特にセクション 10.5「個人情報」）** に厳密に準拠し、データを完全にローカルで処理し、テレメトリを一切使用しない設計について説明します。

---

### 1. 個人情報に関する宣言
* **データ収集ゼロ**：SyncNexus は、個人情報、デバイス識別子、利用状況のテレメトリを**収集、送信、保存、共有することは一切ありません**。
* **リモートサーバーなし**：同期は、お使いのローカルファイルシステム、ローカルにマウントされたクラウドファイルシステム（Google Drive / OneDrive）、外付けリムーバブルストレージの間でのみ行われます。ファイルの内容がデバイス環境の外に出ることはありません。
* **サードパーティ解析なし**：トラッキング、広告、解析、行動監視を目的としたサードパーティ SDK は一切含まれません。

---

### 2. Windows の機能と透明性
1. **ファイルシステムへのアクセス**：
   - ユーザーが明示的に選択したフォルダーの読み取り、比較、同期にのみ使用します。
2. **Windows Cloud Files API の利用**：
   - Google Drive や OneDrive のフォルダー上にある `FILE_ATTRIBUTE_RECALL_ON_DATA_ACCESS` プレースホルダー属性の判定にのみ使用し、キャッシュされていないファイルが意図せずダウンロード（ハイドレート）されるのを防ぎます。
3. **ローカルでのデバイス検出（mDNS マルチキャスト）**：
   - ローカル Wi-Fi 内で、マルチキャスト IP `224.0.0.251:5353` を使って `_syncnexus._tcp.local` を送受信します。**外部のインターネットサーバーへの接続は一切行いません**。
4. **スタートアップ設定（Windows スタートアップレジストリ）**：
   - ユーザーが有効にした場合に限り、`HKCU\Software\Microsoft\Windows\CurrentVersion\Run` にエントリを登録し、バックグラウンド同期の常駐プログラムを静かに起動します。設定画面または Windows タスクマネージャーからいつでも無効にできます。

---

### 3. ごみ箱とデータの安全性
* 削除されたファイルは、Win32 の `SHFileOperationW` を使って**本物の Windows ごみ箱**へ安全に移動されます。
* 削除前に `.syncnexus-history` へアーカイブすることで、多層的にデータを保護します。
